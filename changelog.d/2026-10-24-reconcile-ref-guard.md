- **The backend deploy tool can no longer plan from a stale checkout (2026-10-24, tooling).** `tools/reconcile_live_backend.py` now reads `$SHIPPED`/`$PATCHES` from the `--ref` it deploys (`git show <ref>:scripts/apply-patches.ps1`) instead of the working tree, and it refuses with exit 2 - printing both SHAs and the fix - when the checkout's HEAD is not that commit; `--allow-worktree-mismatch` overrides the refusal for tests and exotic checkouts. An empty `--ref` is refused too - it was the one value that slipped past both halves of the fix, because it would read the file list from the checkout and the module bytes from the git index (`git show :path`). Measured before the fix: a checkout behind `origin/main` planned 251 shipped files and "to add: none" while the ref carried 253, hiding the two modules #790 had added; the dry run stops after that plan, and an `--apply` from the same checkout still ended `RESULT: PASS`.
