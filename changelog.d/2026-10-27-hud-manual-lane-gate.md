- **A lane you pick by hand now runs the same privacy gates as an automatic turn (2026-10-27, F-01).** `POST /api/chat` with `"auto": false` and a `"lane"` skipped every routing gate: any client with the pairing token could send `{"lane": "<cloud lane>", "auto": false}` and have the turn answered on a cloud model with private memory text, a tainted conversation, a picture or the owner's screen attached, because the manual path built its own decision and ran no gate at all. Both paths now go through the ONE `jarvis_router.choose()` call, the pick stands in for the owner's own yes for that one question, and a pick the router would not have escalated is answered on the local model with the router's own `gate` and a plain `reason` in `X-Jarvis-Route` ("you chose <lane>, but this turn stays local: ..."). A pick of the local model is unchanged, no wire field was added, no app changed, and a PC with no `jarvis_router.py` fails closed. `backend/f01-manual-lane-gate.patch`, proved by `backend/test_hud_manual_lane_gate.py`.
