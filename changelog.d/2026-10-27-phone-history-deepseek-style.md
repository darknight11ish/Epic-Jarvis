- **The phone's History gets the DeepSeek conversation-list look, with pinnable chats and one section per project (2026-10-27).** The search box is the first thing on the screen, beside a Sort control (Newest first, Oldest first, Title A-Z) and a **New chat** action that starts a conversation the same way the idle timer does - a new id and a cleared chat on the phone, no new route and no request to the PC. Below them the list is grouped: **Pinned** first, then one collapsible section per chat tag (the owner's projects) with its icon and count, then the chats in no project; a pinned chat appears once, in Pinned, and a tag's header count has the loaded pinned rows taken off it. Rows now carry the conversation's type icon, its title and its age ("25min", "7d"), and the chat Home is in says "You're here". Each row's overflow menu carries Open, Pin/Unpin, Move to and Delete; a long section shows five rows and "Show N more" over what is already loaded, and "Load older" still brings more from the PC. Pin is **metadata only**: `POST /api/history/pin` sends the chat's id and the wanted state, raises no approval card, is held on a stale link, and the row moves only after the PC says yes - a refusal says so and leaves it exactly where it was. Delete from a row asks inside that row, in the same words as Delete inside a chat. Everything already there still works: opening, Continue this chat, Fork from here, delete and confirm, Forget a time frame, History settings, the word search, the Show filters, the Tags editor and hidden lists. JVM tests cover the grouping, pin, sort, age, "Show N more" and menu rules; the Android compiler is CI (`phone-unit-tests`).
