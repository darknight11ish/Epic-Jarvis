- **a reminder can open a page or a file, or raise one card to run a task (2026-10-27).** A reminder may now carry ONE action: show a note, open a web page or a file on this PC, or put the morning briefing together. A page or a file is only a notice with an Open button - nothing opens until it is pressed, and pressing it is the approval (a 15-minute card would expire before "when I get to it"). The button sends the reminder's id only; the PC reads the target back from its own answer and checks it again at the tap (https only, a folder Jarvis may look in, and an extension allow-list that refuses `.lnk`, `.exe`, scripts and `.html`). A task is acting, so it raises exactly ONE `schedule_action` card at fire time and runs nothing if that card is denied, expires or is refused; its detail carries ids and the task name only, so no address, path or note reaches the audit log or the phone. Confirming the design's second target was wrong: a backup is locked with a fresh recovery code that nothing would be left to show, so `backup` is refused when the reminder is saved, with that reason. Creating one is the desktop HUD's; the phone shows a note and the card, and creates nothing (ARCHITECTURE §8).
