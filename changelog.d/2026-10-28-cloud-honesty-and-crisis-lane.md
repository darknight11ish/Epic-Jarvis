- **The cloud lane now says what the local one says, and a crisis turn never leaves this PC (2026-10-28).** From the 2026-10-27 AI-safety audit's H1 and M1. A cloud answer used to be relayed exactly as the provider sent it, so every honesty line a local answer carries - "nothing was actually done", the four newer corrections, and the 988/911 help text - was missing on the one lane where no tool can run and a claim of action cannot be backed at all. It now comes from the same function the local answer uses, written after the model's words and before the stream ends. A turn that looks like a crisis is no longer offered to a cloud lane even when one was picked by hand: it is answered on this PC, and `X-Jarvis-Route` says so (`cloud_refused: "crisis"`). The crisis check is one rule now (`jarvis_wellbeing.crisis_in_turn`, the last message when it is the owner's), used by the route header, the answering turn and the quick path - so a distress message pasted, shared, captioning a picture or said with a failed voice print gets the help line instead of only the calm panel, and the quick path can no longer answer a crisis turn before any check runs. The claim classifier also catches the short confirmations it used to miss ("Reminder set for 7pm."), no longer exempts a sentence just because it says "noted" while writing a note, and no longer counts four read-only tools as actions. One limit, said plainly: the route itself needs the owner's PC and a real cloud key to drive end to end, which this change does not do.
