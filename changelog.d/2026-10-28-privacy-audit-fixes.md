- **The HUD's memory graph now forgets when the private lists hide, and the hidden-lists setting blocks desktop captures on its own (2026-10-28).** The seven findings of the 2026-10-27 privacy audit (`.dsh-scratch/AUDITS-2026-10-27/PRIVACY.md`). P-1 (High): `emit_private_hidden` broadcasts `private-hidden` to every window instead of two, and the HUD page listens for it and for `security-changed`, drops every word it holds (the galaxy's nodes and labels, the inspector, the search box, the recall trace, the trail of the owner's own questions, the node buttons) and then re-reads `/api/graph`, which comes back redacted - so a Show that ended can no longer be read off a map that was already drawn, and the counts line says "Memory lists are hidden until you unlock." in `hud-safety.js`'s own words instead of claiming "no saved facts on this PC yet". P-2 (the owner's decision, 2026-10-28): `capture_blocked_from` checks `private_hidden` BEFORE the owner-is-here answer, so "Hide memory lists and chat history" alone keeps Jarvis's windows out of a screenshot on the PC as it already did on the phone - it could never block anything before, because `app_locked` is false whenever App lock is off. P-3: the phone's one-time backup recovery code now raises `FLAG_SECURE` while it is drawn (`Backup.codeShown` -> `SecurityRules.blockScreenCapture`'s new `codeShown`), so a screenshot, a cast or the recent-apps picture cannot take the one key to a backup. P-5: the two toasts that carried the PC's own words (a reminder that would not open, a Snooze answer) go through `notify_guarded`, with fixed sentences that keep the meaning. P-6: `docs/ARCHITECTURE.md` no longer says the desktop has no screenshot block, and the HUD's Reminders comments now match the code (the panel is re-read on the same event). P-7: Live's and "Live ended - Resume"'s notifications are redacted on the lock screen by the shared `notificationsLocked` rule. **P-4 was not a bug and no code changed for it:** the report's mechanism does not exist - in Tauri 2 a page's global `listen()` registers with the target `Any`, and `match_any_or_filter` lets an `Any` listener through every filter, so the widget's `private-hidden` listener already fired before this PR (`tauri-2.12.5/src/event/listener.rs:346`); the broadcast keeps it true by construction. **The limits, plainly:** Live's foreground notification still tells a stranger that Jarvis is on this phone - a foreground service must show a notification, and `VISIBILITY_SECRET` is not honoured for one - so what was removed is the session's own state line (minutes left, Mic off/Mic on, the PC's why); and while "Hide memory lists" is on, desktop captures are blocked nearly all of the time, which is the cost the owner chose with P-2. No route, command or token changed.
