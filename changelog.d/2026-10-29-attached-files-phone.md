- **The phone can attach a file to a question, and the PC reads it (2026-10-29).** "Put this thing in front of Jarvis" is the commonest thing the owner does with a file, and on the phone it now takes one control instead of three: **More → Attach a file** opens Android's own file picker (`ActivityResultContracts.OpenDocument()`, the same door the custom-voice WAV already uses) filtered to the seven kinds `my_files` already reads - PDF, Word `.docx`, Excel `.xlsx`, PowerPoint `.pptx`, Markdown, text and CSV. The file rides inside the **newest user message** as one `attachment` object (`name`, `mime`, `size`, raw base64 `data`) with `"has_file": true` beside `has_image`, in the same `/api/chat` body, over the same private link, under the same token - **no new route, no upload, no new permission, no new switch**. The PC turns the bytes into text itself (at most 12,000 characters, with a sentence saying how much was left out) and keeps the turn on the local model; the router's `has_file` gate refuses any cloud lane, and the chat counts as having read outside text, so a later web search or note still asks first - the chip says so. The cap is **2,500,000 raw bytes** (base64 grows it by a third; the largest allowed file plus the most conversation the phone sends is about 3.55 MB against the PC's 4 MiB body cap), refused with the real size and the one thing that works for a bigger file ("put it in a folder Jarvis may look in"). **Nothing is written anywhere on the phone:** the bytes are read straight into memory, never to storage, a preference, a Bundle or the log, and they are dropped the moment the question is sent - the chip goes with them, because the file is not kept and a later question does not carry it. No preview and no text extraction on the phone: the PC is the only place a file's words are read. Pictures keep their own path, untouched. Tests: `AttachFileTest.kt` (the cap to the byte, the refusals' exact words, the names, base64 correctness, the four wire fields exactly as the backend fixture has them, `has_file` beside `has_image`, and that a later question carries neither) and a new case in `ApiContractTest` read off the wire through the real `ChatSession`. **Not proven on a phone:** no APK from this branch has been installed - GitHub Actions is the only compiler for this app, and the first real attach is one CI APK and one picked PDF away.
