- **Edit HUD can put any feature on the main screen (2026-10-29).** The owner asked (2026-10-29) that the features they want within one click be addable to the main screen from Edit HUD, with an equivalent edit screen on the phone. This slice is the desktop half: a catalogue of 24 feature cards keyed by the feature's own id in `features/features.json`, a "Main screen cards" panel inside Edit HUD (Add, Remove, move earlier/later, fold away, reset), and a strip at the top of the HUD's stage that draws exactly the cards chosen, in the order chosen. A card whose feature is off says so in a whole sentence ("Calendar is turned off. Turn it on in Settings."), never a blank box and never JSON. The safety surfaces - the approvals queue, Stop everything, app lock, What asks first and the stale link - are deliberately not in the catalogue, so no layout can hide or move them. `tests/home-cards.mjs` (24 checks) covers add/remove/reorder and proves a brand-new feature key can be added by one catalogue row and appears. The phone's equivalent edit screen is the next slice; `docs/HUD-MAIN-SCREEN-CARDS-2026-10-29.md` carries its work order.
