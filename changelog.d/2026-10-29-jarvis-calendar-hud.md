- **The desktop HUD has the owner's own calendar: month, week and day views, one Add/Edit form, and a card he can place from Edit HUD (2026-10-29).** The owner asked for "a full fledged easy to use calendar built into Jarvis", local only and disableable. This slice is the desktop half of it: a Calendar card in the HUD, a sheet with Month (a six-week Sunday-first grid), Week (seven columns and one band for all-day and spanning events) and Day views, and ONE form that adds or edits an event - title, date, all day, start and end, last day, a reminder saved with the event (nothing rings yet), place, a daily/weekly/monthly repeat, and notes. It reads the one local store through `GET /api/calendar?days=90`, and writes through two commands of its own, `hud_calendar_add` and `hud_calendar_act`, so the page still holds no pairing token; neither write raises a card (one row on this PC, no list form, no delete-all), and both are held on a stale link. Titles, places and notes are blanked while App lock or "Hide memory lists" is on, and the days, times and counts stay. EVERY STATE IS SAID IN WORDS: the switch turned off ("The Jarvis Calendar is off. Nothing was deleted..."), an empty week, a day with nothing on it, and a read that failed - never a blank card, and no countdown anywhere. The card is a real card the owner can place: it is in the HUD's layout registry and in Edit HUD, every built-in preset carries it, `contract/hud-presets.json` mirrors them, and a card added after the owner last saved a layout is put back into that layout rather than hidden from Edit HUD for ever (his rule that every easily-accessible feature must be addable to the main screen from Edit HUD). Also fixed, found by the new test: an event's moment was computed from a NOON anchor, so every event read as "upcoming" and the card listed events that had already ended. The store, the four routes and the feature's own switch are the backend slice's; the phone's plate and widget are its own slice. `tests/hud-calendar.mjs` (31 checks) runs the page's own calendar block against a tiny fake document.
