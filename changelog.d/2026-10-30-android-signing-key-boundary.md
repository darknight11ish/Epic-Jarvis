- **The phone keeps its shared debug signing key, and rotating it is now one command (2026-10-30).** The owner accepted the sideload boundary Gemini's Q4 ruling named: the app is signed with one shared debug key, sideloaded onto his own phone only, and updated only from this repository's release over https with the APK's certificate pinned in the app - so the key stays for now, and the record says exactly when that has to change (public distribution, the APK handed to anyone else, or the repository made public with release assets). Replacing the key costs one `adb uninstall` and a re-pair, because that is what Android requires when the certificate changes. `scripts/rotate-android-signing-key.ps1 -Rotate` does the key half of that ceremony: it makes a new keystore outside the repository, refuses without the flag and refuses to overwrite, reads the alias and password from the build file rather than carrying them, and prints the new fingerprint with the remaining steps. It changes nothing else. **Honest limit:** only the owner's phone can prove the new APK installs and pairs again - this was run against a throwaway key in a temporary folder, never against the real one.
