- **The phone's History and More menus are simplified: one filter row and one Filters button, and a More sheet of five doors (2026-10-30).** The owner sent screenshots of the latest app and said *"these both screenshots need further simplification, too many options"*, then chose *"Tuck the rare ones behind one Filters button."* History used to draw three chip rows - the conversation kinds, the tags, and the same tags wrapping onto a second line with Untagged - under a "CONVERSATIONS / Tags / Forget a time frame…" line. It now draws ONE row: the owner's tags as quick chips ("All", "Work", "Learning", "Personal", …) that scroll sideways instead of wrapping, with a **Filters** button at the end whose dot (and TalkBack count) says when one of its filters is on. That button opens ONE flat sheet - the same quiet Dialog shape as Home's More menu - holding everything that was there before, still combining exactly as it did: the conversation-type filters (All chats, Just chats, Live only, Support chats, Chats with other AIs, Comparisons) and the Archived view; the full tag list with Untagged (so nothing depends on a sideways swipe); the **Tags** editor; and **Forget a time frame…**. Applying updates the list immediately, and the sheet follows the same "hide memory lists and chat history" guard the tag names do. The More sheet is short on purpose: **New chat, Photo, Attach a file, Modes, Quick note**, then Close (plus the conditional Notifications row, kept direct because it is the only door to attaching captured notifications and one sheet deeper would make it three taps). Think, Coach this and Incognito moved one tap deeper, behind the one **Modes** row in a small sub-sheet, each behaving exactly as before with the same offer gates. Earlier chats left More because it opened History and History IS the list (Home's status line opens it in one tap); Pinned messages moved into History's own header as one compact **Pinned** action that opens the same PinnedScreen; Jarvis Presets left More for Home's existing one-tap "Presets →" door beside the Galaxy. NOTHING was dropped - only relocated, and every capability stays reachable within two taps. The desktop app is deliberately unchanged: this is a phone-only simplification, on a phone that does not show the desktop's HUD/menus, so no parity row or one-sided note is needed. Proven by the full local JVM suite (2,955 tests, 0 failures, including the updated source-pin tests: ChatMenuTest, AuditPlumbingTest, HistoryArchiveTest and PresetsLandingTest now assert the NEW contract rather than the old rows) and `tools/check_parity.py`; **not proven on a phone** - no APK was built from this branch, so the field-test step is the CI-built APK on the owner's phone: open History and More, open Filters, pick a tag and a kind, open Modes and turn Incognito on.
