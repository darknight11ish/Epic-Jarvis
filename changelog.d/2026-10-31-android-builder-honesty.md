- **Jarvis can really build an Android app, and now says so (2026-10-31).** Asked "are you able to build android apps for me?", Jarvis said it could not build Android apps because it had no tools to write code or compile projects - false. The tree ships the `android-builder` plugin and `backend/jarvis_android_builder.py`: in a project task it writes a fixed minimal WebView Android project around the owner's own index.html/app.js/app.css, then `gradlew.bat assembleDebug` runs behind ONE `app_build_android` card and `adb install -r <apk>` runs behind ONE `app_install_android` card over the cable. It needs the Android SDK, a Java 17 JDK and its Gradle wrapper files (plus adb and USB debugging for the install); a first build downloads Gradle and the Android Gradle plugin; there is no hand-written Kotlin/manifest, no permissions, no release signing and no Play Store.
