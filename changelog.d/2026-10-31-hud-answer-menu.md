- **The desktop HUD's per-answer "Was this answer right?" row is now a caret menu (2026-10-31).** The owner asked for the always-visible Right/Wrong line under every Jarvis answer to be gone, replaced by a small caret menu beside the answer: "was the answer right?", "read out loud", and the other real options. Each finished answer now has one quiet caret ("Answer options"); opening it shows **Right** and **Wrong** (the same feedback path as before - the shell's `mark_answer` command with the same `{turnId, mark}` body, so the recorded learning signal is unchanged; pressing the chosen mark again takes it back, and a PC without the route removes the menu quietly), **Read out loud** (clicks the page's own per-answer speaker, so the voice, its rate, its pitch, the local-voices-only rule and the read-aloud privacy gate are all the existing ones - the item appears only when that real speaker exists), and **Copy answer** (the answer's own words to the clipboard, with "Copied." in place). No History jump is invented - the HUD has no per-conversation door, so it is not listed. One menu at a time; Esc closes and returns focus to the caret, an outside click closes, arrow keys move between items, the caret is low-emphasis until hover/focus, and no text is drawn before it is opened. The answer text and message order are untouched. Tests: a new browser-free pin (`tests/hud-answer-menu.mjs`, 9/9 here) holds the old row gone, the real options only, the same `mark_answer` body, the page's own speaker path, the clipboard copy, and the one-at-a-time/Esc/outside rules; the Playwright HUD suite drives the caret, the menu, Right/Wrong and Esc in the real page (CI).
