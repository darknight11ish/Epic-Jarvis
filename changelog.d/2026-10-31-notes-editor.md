- **You can now read and edit every note in your Obsidian vault from both apps (2026-10-31).** The Brain gets a Notes plate on the PC and on the phone: search the vault, open a note, edit it, and Save — which raises exactly one approval card on the PC (the app never approves anything itself). Before anything is written the old bytes are copied through the File Guardian, so a bad save is recoverable; a save whose edit started from an older version is refused with `conflict` and the current version instead of overwriting; and the edits stay inside the configured vault (absolute paths, `..`, links, junctions, hidden folders and non-`.md`/`.txt` files are refused before any card; 2 MiB per note). The phone shows the PC's own plain sentence when a note was denied, conflicted or lost, and the whole plate sits behind the phone's existing lists' Show gate with no new bypass. **Honest limits:** no creating, deleting or renaming notes in this slice; search matches note titles and paths, not full text; and it is implemented and proved locally but **not deployed to the live PC yet** — the four `/api/notes/*` routes need their own deploy pass before the live apps show it.
