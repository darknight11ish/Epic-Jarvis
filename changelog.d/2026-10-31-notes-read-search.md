- **Read and search your Obsidian notes from chat:** ask "what does my <title> note say?" (or "read my note <title>", "what is in my ... note?") and Jarvis reads that note from the vault and quotes it - bounded to the first 4,000 characters, then says how many more there are - naming the note only when the memory lists are not hidden. "Find my notes about <x>" / "which notes mention <x>" matches titles first and then bounded content, answers with the count and up to five titles (never bodies), and says where the real vault search lives when nothing matches. "Open my <title> note" names the note and opens the existing Brain window where the Notes plate is. "Read my notes" is refused with "I can read one note at a time; tell me which one." All of it is deterministic (no model), read-only (no card, no route, no tool), uses the same vault resolution, protection and hidden-folder rules as the notes editor (`.obsidian` and paths outside the vault are never read, notes over 2 MiB are refused), and while "Hide memory lists and chat history" or App lock is on it shows no note title and no note word. Proved by `backend/test_notes_read_search.py` on a throwaway vault.
