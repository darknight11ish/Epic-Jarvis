- **Rename and move a note from the desktop Notes plate:** the editor's chrome now has **Rename…** and **Move…** beside Save, calling the same wave-4 routes the chat uses - `POST /api/notes/rename` with exactly `{"path", "title"}` and `POST /api/notes/move` with exactly `{"path", "folder", "create_folder"}` - and following the job with `GET /api/notes/change?id=`. Rename is pre-filled with the current title and disabled when the note has no path. Move offers every folder the editor's own note list proves exists (plus the top level) and a new-folder field whose **"Create it if it does not exist"** checkbox is the only way `create_folder` can become true. The PC's ONE ordinary approval card decides; the plate only asks and follows, shows the module's own waiting/denied/failed/saved words (including "You can undo it."), and opens the note at its new path after a saved change. No second write path, no autosave, no approval from the window, and no rename/move of folders.
