- **Renaming and moving Obsidian notes, keeping their links working (wave 4, 2026-10-31).** Say "rename my Welcome note to Home" or "move my Welcome note into Projects" and Jarvis plans the path change plus every link that named the note - `[[old]]`, aliases, sections, embeds and relative Markdown links - shows the old path, the new path and "2 links in 1 note" (or says there are no links), names up to the first three affected note files when lists are visible, and raises ONE ordinary approval card. Code fences and inline code are never touched; a missing folder is refused unless you explicitly say "create the folder"; two notes with the same title are refused with the count. After approval the File Guardian copies the note and every note whose links change, only those link bytes are rewritten, and the note is moved atomically; ONE Undo puts every byte and path back. Deleting notes, moving outside the vault, renaming folders and renaming onto an existing name stay unbuilt and are said so plainly.
