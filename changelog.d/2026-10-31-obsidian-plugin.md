- **Jarvis becomes a first-class guest inside Obsidian: a new first-party plugin in `obsidian-plugin/` (ribbon, commands, right-side panel, selection actions) that asks the local Jarvis and drives note edits only through Jarvis's own one-card routes (2026-10-31).** `jarvis-notes-bridge` 0.1.1 (desktop only, min Obsidian 1.13.0) talks to `http://127.0.0.1:4719` with `X-Jarvis-Client: hud` and `X-Jarvis-Surface: desktop` through Obsidian's `requestUrl`, and never writes the vault itself: there is no `Vault.modify`, no `editor.replaceSelection`, no `/api/approve`, no `/api/deny`, no `obsidian://` write action in the bundle, and the token is read at request time from Obsidian SecretStorage (with a plainly warned plain-text fallback) and is never logged or put in a URL. Wave 1 (read-only plus capture) works on the shipped backend: ask about the note or the selection (`POST /api/chat`), capture to today's daily note (`POST /api/notes/capture`), and a right-side panel showing the note's headings, links, backlinks, unresolved links and frontmatter keys from Obsidian's own cache, bounded. Wave 2 (structured edits) drives the routes built on PR #1049 with the same one-card flow - insert one line under a chosen heading, bold/italic the selection, replace the selection, turn its line into a checklist item, tag the note, and create one note from a vault/Jarvis template - each showing the PC's own card sentence and polling `GET /api/notes/change` until the card is answered outside the plugin; until the notes-editor backend deploy reaches the live PC those buttons answer honestly that this backend does not have the route yet. Ships with node tests for URL/header building, answer parsing, error mapping and template labels, a `BUILD-VERIFICATION.txt` (typecheck, esbuild bundle, `node --check`, JSON checks, safety greps, a test-vault copy dry run and the zip's SHA-256), and README/INSTALL/SECURITY documents; the shipped tree is unchanged apart from this new folder and this one bullet. Honest limits: the plugin has NEVER been loaded by Obsidian - Obsidian is installed on this PC, but this work never opened it, never installed the plugin and never touched a vault - and no live card flow has been driven; every one of those checks is UNTESTED, not passed.
