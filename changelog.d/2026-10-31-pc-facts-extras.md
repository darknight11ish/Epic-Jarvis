- **PC facts now include the CPU model and the graphics card's live temperature, utilisation and VRAM used/total (2026-10-31).** The chat's PC answers read the CPU name from Windows' own registry (`HKLM\HARDWARE\DESCRIPTION\System\CentralProcessor\0\ProcessorNameString`, with `platform.processor()` as the fallback) and the NVIDIA card's live temperature, percent busy and used/free/total memory from the same nvidia-smi health reader PC help already uses. Serial numbers, UUIDs and user paths are stripped from the names; only drive letters remain for disks. A missing sensor or a non-NVIDIA card still says "not readable", never guessed, and the PC help feature row says the same.
