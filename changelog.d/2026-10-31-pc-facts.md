- **The chat can now answer questions about this PC's disk, RAM, CPU, GPU and uptime (2026-10-31).** Asked "how much storage does my computer have available?", Jarvis used to say it had no access to system storage; the facts were already read on the PC. A small read-only layer (`jarvis_pc_facts.py`, reusing PC help's own kernel32/nvidia-smi readers) now answers the real numbers in plain words: every fixed drive's free/total/percent, RAM total/free, CPU logical cores (its model name is not read anywhere, so it says "not recorded" rather than guessing), NVIDIA card names and VRAM, uptime, and whether the C: drive is under the 25 GB safety margin / 3 GB emergency floor the model chooser uses. Only drive letters are named, never a user name or a path. The older PC-help phrases keep their own topics; "how much storage does Google give me?" is not captured. A local prompt gets the current model/focus-preset line only when the question is about this PC, so an ordinary prompt keeps its old bytes. The PC help catalogue row now states these facts and limits.
