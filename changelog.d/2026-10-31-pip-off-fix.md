- **Picture-in-picture "Off" now really means off (2026-10-31).** The privacy check ran *before* the setting, so with "Hide memory lists and chat history" on, a stored Off evaluated to the hidden layout and Android's auto-enter was armed anyway — a small window could still appear after Home, and even after a fresh process start with Off stored (field-test F-13). The setting is now decided first, so Off wins always; auto-enter is keyed on the stored mode rather than the layout (the hidden layout stays enterable when the mode is on, as the design requires); and the truth table plus a new regression test pin both the source order and the call site so a future reorder cannot silently bring it back. **Fixed in code only:** the installed APK still has the old behaviour until a newer client-latest build is installed — recorded as DEF-023.
