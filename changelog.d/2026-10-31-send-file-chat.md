- **The chat can send one file to the phone (2026-10-31).** "send me the file X", "send X to my phone", "send the file X to my phone", "find the file X and send it to my phone" and "send me X from my Downloads/Documents/Desktop" are answered by a deterministic fast path that calls `jarvis_send_file.prepare()` itself - the same allow-list search, the same one-card rule and the same plain refusals - and raises the module's own card under its own `send_file_to_phone` action. No new route, tool or permission, the fast path approves nothing, and the answer is the card's own sentence plus "Nothing is sent until you approve the card." A no match, several matches, a protected/outside file or a file over 10 MiB returns the module's own sentence with no card; "send an email", "send me a message" and "send my regards" stay the model's.
