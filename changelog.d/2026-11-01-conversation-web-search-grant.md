- **"You have full approval to search the web for this conversation": one card, once, and search only.** Say that sentence in a chat and Jarvis raises ONE approval card; approve it and web searches in that chat stop asking for the rest of the conversation - everything else still asks every time. The grant covers `search_the_web` and nothing else: booking a flight, sending an email or a file, spending money, deleting, running a command, changing a setting and working a browser each raise their own card with the grant live, because the only code that reads a grant is the web-search path. It is ended instantly by saying stop ("stop searching without asking", "you don't have approval", "revoke that") with no card at all, by the chat ending, by an 8-hour cap, or by a restart - it is never a setting, and nothing about it is written to disk. Lockdown outranks it. Every search it covers is written in the approval log with the grant's id (`gate.grant_made`, `gate.granted`, `gate.grant_ended`), and the conversation id never is. The model can ask for the grant but can never decide it: a denied, timed-out or unanswered card grants nothing, and the tool is one a person must answer even if the tier is loosened. Both tools are switched on in Settings, Tools, "Safety and sharing" (`approve_web_search_for_conversation`, `stop_web_search_approval`); neither is a fresh-install default.
