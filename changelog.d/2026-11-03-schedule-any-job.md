- **Scheduled tasks can run any job in the owner's own words (2026-11-03).** A reminder's `run-task` action may now carry `job` - a phrase in the owner's words - instead of only the closed `briefing`/`backup` names (which are unchanged). The phrase is resolved through the same `jarvis_quick.match` path chat uses when it is saved (an unresolvable phrase, or one asking for a shell/command/script, is refused in one plain sentence) and again at fire time (a phrase that no longer resolves raises no card and runs nothing). At fire time it raises exactly ONE `schedule_action` card, tier ask, whose body names the action in plain words and says nothing happens before a yes; denial/timeout runs nothing. Approved, it runs through `jarvis_quick.run` - the same executor chat uses - so the module adds no shell, no command line and no second interpreter. The owner's words never reach the audit log or the card's `detail`.
