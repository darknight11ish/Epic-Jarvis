- **Four read-only abilities now come switched on for a new install (2026-11-04).** A fresh Jarvis can say what it is made of (`self_portrait`), re-read its own abilities (`refresh_abilities`), find an old chat by what it was about (`conversation_find`, titles and dates only, never the words) and reopen one kept chat so this PC's local model can answer about it (`conversation_open`). All four read only Jarvis's own registry, modules and the conversations this PC already kept, change nothing and raise no approval card; `conversation_clear` stays out of the model's hands on purpose, because an AI must never have an autonomous tool to wipe a transcript, so clearing keeps its one card. A PC that already has a settings file keeps the list it had - an update never overwrites that file - so this reaches new installs, or the owner's own file once the four names are added there.
