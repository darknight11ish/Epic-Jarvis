- **The tray's "Update Jarvis to <version>" row now waits for App lock (2026-11-04).** With App lock on and Jarvis locked, pressing it starts nothing until Windows Hello confirms it is the owner: the row runs the both-halves update against the live backend, so it now uses the same lock prompt the tray's window rows already show. Declining says in a notification that the update was not started; with App lock off, or the owner still at the PC, the press behaves exactly as before.
