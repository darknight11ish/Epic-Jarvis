- **The tray's "Update Jarvis to <version>" row now updates both halves, like the Settings Install press (2026-11-04).** One press there runs `update.rs`'s `update_both` - the backend is patched first, then Jarvis Desktop installs - instead of the desktop-only `install_update`, so the Update control the owner reaches from the tray can no longer leave the two halves out of step. The toast before it says what is about to happen (the backend first, then the desktop, Jarvis closes and starts again, several minutes), because the tray has no card to say it in. The desktop-only path survives only where the backend half cannot run at all (the two folders are not set, or the patch program is missing) - the same check the Settings Updates card makes - and there the toast says plainly the BACKEND was NOT updated and where to finish it, before and after the install. The row's own states are unchanged: absent while no update exists, "Updating Jarvis to <version>…" and disabled on the press, and rebuilt from a fresh check if the run fails.
