- **Seven bugs found by the #1209 follow-up audit are fixed, and no gate is loosened (2026-11-07).** PR #1209 made an explicit action request reach its gating tool; the standing audit of that feature found seven ways the new answers could still be false, wrong or needlessly refused. (1) A draft-only request ("write an email") no longer gets the "sending is off, nothing ran" line when a draft really ran - the SEND pattern now matches send/sending/sent, not "write", and a `draft_email` step in the turn suppresses the line. (2) The switched-off-tool correction quotes the real Settings -> Tools row label through `jarvis_asks_first.tool_label` (the old label stays only as a fallback), so "Settings, Tools, \"<label>\"" names the row the owner will actually look for. (3) "Don't forget this fact" and "Do not forget this fact" are no longer read as a request to FORGET the fact: the words immediately before the verb are checked for a negation. (4) The phone read-aloud correction now says the switch covers the mic and a typed answer's "Read aloud" on that phone, which is what it has covered since the feature was extended. (5) The refusal of a plugin/skill link names the chat door (ask in chat to install from a folder or a .zip, where the scan and its one card happen) instead of a Settings installer that does not exist. (6) `CARDS_PER_TURN` is now read only for the request that would raise a card - an ON while the switch is OFF - so an instant OFF, or an ON on a switch that is already on, is never refused in words by a limit about cards. (7) An already-on or already-off cloud call is recorded as a finished call (`ran`, `ok`, kept in `tools_ran`) instead of "not allowed"/"refused", with the module's own words handed back to the model. The same audit corrects `docs/ARCHITECTURE.md`'s account of #1209: the merged change left the lane rules byte-identical to `main` (the rewrite was reverted before merge), so the call-it instruction lives in each tool's own description. `backend/test_action_requests_reach_the_gate.py` grew from 51 to 77 checks, all passing; the audit did not drive the six probes live.
