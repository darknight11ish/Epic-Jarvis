- **A repository watcher you can steer by voice or typing:** say "watch darknight11ish/Epic-Jarvis", "watch your repo daily", "watch it for new releases and issues", "stop telling me about it", "resume watching it", "tell me weekly about that repo" or "follow new repos for topic mcp" in chat or in Jarvis Live and it obeys - one sentence, the same answer both places. Each watch follows any combination of new releases, commits, issues, pull requests and CI changes at instant, daily, weekly or pull-only cadence; it starts in observe mode and tells nobody until the owner answers the one approval card that starting it raises. Public repositories work with no GitHub token at all, and every poll is conditional (`If-None-Match`), so an unchanged repository costs zero GitHub rate-limit points. Duplicate items are never announced twice, ordinary notifications can never ring or interrupt, and the log of what it would have said is the existing `GET /api/watch/decisions`. Starting one creates the repeating job that actually checks every ten minutes, through the scheduler's own `add_repeat` - the same one-card path the older "tell me when CI fails" GitHub watch uses - so "watch X daily" really polls after the yes, and "forget X" deletes the check with the watch.
