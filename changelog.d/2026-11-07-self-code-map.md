- **Jarvis now knows the major parts of its own code, and where its own repository is (2026-11-07).** Asked "what is your own GitHub repository?", the live backend answered "I don't have a public GitHub repository of my own" — the one fact it was missing about itself. Its code IS the public `darknight11ish/Epic-Jarvis` repository, so a generated map of that tree now ships beside the backend: `backend/jarvis-self-code.json` is written by `tools/gen_self_code_map.py` (deterministic, standard library, no network, no absolute paths) from the deployed tree at the commit the deploy was built from. It carries the five runtime parts in the order they fit (backend on the PC → Ollama → the Tauri shell → the Android client → the public repo with its CI and deploy), then one row per major part of the code with its purpose, every file it owns, the key modules to start reading (with the first sentence of each module's own docstring), the suites that prove it and the documents that describe it — plus the commit, its date, the version and the newest twenty commit subjects. Completeness is checked by construction: the generator exits non-zero and names every path when a tracked file belongs to no subsystem or to two, and generated/binary/vendored files are skipped only through an explicitly named list whose counts it prints and stores. `backend/jarvis_self_code.py` (shipped whole, twin kept) only reads that file beside itself — no git, no socket, no write, no model, no code body — and says "the self-code map was not installed with this build" when it is absent. Four deterministic chat intents in `jarvis_quick.py` answer from it: the overview, a lookup ("where is the code for X"; "what does X do" only when X is really in the map), what changed recently (saying plainly it is as of the deploy that built the map) and the public repository identity. A miss says "not in the map I was built with" and names the two nearest parts, never a guess; all four are read-only, and the existing version, tools, GPU, memory-count, identity, feature and "where did I put" answers keep their own sentences (pinned). `--check` fails on drift, `docs/SELF-CODE-MAP.md` says how to refresh it, and `backend/test_self_code.py` (82 checks) proves the generator, the coverage failure, the map shape, every answer, the miss, the missing map and the old owners.
