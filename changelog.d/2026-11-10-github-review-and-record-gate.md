- **Review a branch, and check the records, before a push:** two new cardless, read-only gates and two chat sentences. `review_changes` prints the review packet - the base and head commits, the line counts, the changed files by area, and the risk flags with the evidence (a one-sided backend twin, no test changed, a new document without the docs count, a tool or route without docs/JARVIS-API.md, tracked scratch, a dirty tree, the size) - and `check_records` answers READY, NEEDS-RECORDS, CHECKER-FAILED or INCOMPLETE by applying this repository's own record rules and running its twelve read-only checkers. Both read one git checkout on this PC, write nothing, open no socket and read no GitHub token, so neither raises a card; both ship off behind their own switch, and "review my branch" / "check the records before I push" are answered without the model.
