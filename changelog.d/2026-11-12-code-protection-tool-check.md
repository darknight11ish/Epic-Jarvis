- **A code-protection tool check that says what it does not do (2026-11-12).** Asking Jarvis which obfuscation or hardening tools are installed on this PC now answers from a read-only check of the seven programs it knows: whether each one is present, the version line it reports, and the install command if it is missing - and then says plainly that this build cannot obfuscate or harden code, raises no card, and changes no file. Asking Jarvis to obfuscate or harden a project gets the same honest refusal instead of a promise of an approval card. The one version probe is started with the allowlisted child environment, never the backend's own, so the pairing token and API keys never reach a third-party program.
