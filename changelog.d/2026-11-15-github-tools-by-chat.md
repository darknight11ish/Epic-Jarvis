- **The GitHub tools are a switch you can say, ask about, and change by talking.** The twenty-tool master switch had a card and a writer but no spoken name, so "turn on the GitHub tools" reached the AI model, which offered to raise a card it had no door to raise, and "what GitHub tools are switched on" was answered "I don't have access to a list of which GitHub tools are currently switched on for you" — a denial of a fact this PC holds. Now the group is a name in the registry's closed-world tool table (a single tool's own name still wins), the switch grammar accepts the plural "tools", and "enable the github tools" is no longer answered as a request to save a token. "What is enabled" has its own short answer — the live count from `jarvis_asks_first.tools_status`, then the exact sentence that changes it — and it never offers to switch on what is already on. ON is still ONE card plus Windows Hello and writes nothing until a person answers; OFF is still instant and cardless. A model-driven `change_setting` call reaches the same group card, and only that one: every single-tool switch keeps its two existing doors.
