- **The phone tells Jarvis which phone it is, so answers can be phone specific (2026-11-15).** The Android app now sends `X-Jarvis-Device` beside the two headers it already sent: the handset's model, Android version, screen size and app build, in one bounded line of five known keys. The shipped gate that every request already passes reads it once, and the one system sentence the model is given names the phone and asks for an answer sized to it. Without the header - the desktop, an older app, a script - every answer is byte-for-byte what it was.
