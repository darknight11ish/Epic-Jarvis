- **Four awareness questions stop being the model's guess (2026-11-16).** An audit on 2026-11-15 asked the live backend nineteen awareness questions and checked each answer against the machine; eleven had no fixed answer at all and fell through to the 8B model, which cannot measure any of them. PR #1292 fixed two. This lands the four of the remaining eleven that a real local read can settle: *"what models are loaded"* now reads Ollama's own `/api/ps` and says **"Nothing is loaded right now"** when it is empty, quoting the loaded model's memory, card share and context when it is not; *"how many models are installed"* (and which) reaches the existing installed-model answer that already leads with the count; *"what is my disk space"* reaches the PC-facts disk answer ("how much disk space is left" already got it) and so names **every** drive - the audit's gap there was the wording, not a missing read, and a narrower one-drive answer was dropped rather than added beside the wider one; and *"is ollama running"* reports whether the lane's own server answers, using the same `/api/tags` probe both apps' lane warning makes. Every answer names the read that produced it, keeps to a phone-sized sentence, and when the read fails says plainly **"I could not read ... so I cannot tell, and I will not guess"** - it never falls back to the model, never invents a number, and never upgrades the configured model into a running one (it is **set to use**). The remaining seven questions (*phone model*, *connected to my phone*, *mailbox*, *which card runs the model*, *what are you doing*, *what can you not do*, *how many interruptions are left*) are deliberately left alone: their honest source is the phone's own facts or a measurement nothing on this PC makes.
