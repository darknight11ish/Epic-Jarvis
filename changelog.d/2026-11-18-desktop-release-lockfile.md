- **The desktop release can build and publish again — the two things #1319 left behind are fixed (2026-11-18).** #1319 (merged 2026-11-16) added the bindings pilot's `typescript ^5.9.3` devDependency without regenerating `jarvis-desktop/package-lock.json`, so every `Desktop release` run after it — eight in a row, from #1319's own merge to #1375 — failed at `npm ci` with `npm error Missing: typescript@5.9.3 from lock file`, and the rolling `desktop-latest` installer stayed at 0.2.465 from `589ba09`. Regenerating the lockfile with npm 12.0.2 adds just the missing `node_modules/typescript` entry (and the root `devDependencies` line); no dependency version moved. That fix let the release reach its build step for the first time since #1319 — and showed the pilot's second leftover: its second binary (`src/bin/export_bindings.rs`) means `tauri build` cannot tell which binary is the app, and it dies with `failed to find main binary, make sure you have a package > default-run in the Cargo.toml file`. `Cargo.toml` now carries `default-run = "jarvis-desktop"`, exactly the line that error asks for, and the exporter still runs as `cargo run --bin export_bindings`. The workflow keeps `npm ci`, so drift still fails loudly instead of being resolved silently.
