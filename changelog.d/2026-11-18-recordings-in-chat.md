- **A recording can be attached in the phone's chat - the owner's `.m4a` voice memo now attaches, and the PC transcribes it (2026-11-18).** The chat "Attach a file" row offered only the eight document types while `jarvis_media_read` already read eight audio formats, so the picker was narrower than the PC's capability: the row now offers `.wav .mp3 .m4a .aac .flac .ogg .opus .wma` (with `audio/x-m4a` beside `audio/mp4`, and the extension decides before any provider type, so a picker that reports `application/octet-stream` for an `.m4a` still attaches it), and `jarvis_attached_file` sends those bytes to that same local reader - transcribed on the PC, never on the phone and never sent anywhere - with its own sentences passed through unchanged, so a PC with no ffmpeg still answers `NO_FFMPEG` in exactly the existing words. A WAV is decoded in memory; a compressed recording is decoded through ONE private temp copy removed before the read returns.
