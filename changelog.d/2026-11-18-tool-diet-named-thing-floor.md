- **The tool diet can no longer hide a tool the owner's own words name (2026-11-18).** The 17:57Z live battery asked eight real questions about the owner's own GitHub repository through `/api/chat`; "What is the latest commit on main in Epic-Jarvis?" was shown only `web_search` and `feature_guide` - every GitHub tool was dieted away, so the model could not call one and answered "I don't have direct access to your GitHub repositories", a false denial of an ability this backend has. The measured cause was the diet scoring a tool by ITS OWN hint words: every GitHub tool's hints open with `github`, and the owner says "Epic-Jarvis". The fix is a **named-thing floor** (`jarvis_agent.NAMED_ACTION_TOOLS` + `named_action_floor`): when the sentence names a repository, pull request, commit, branch, defect register or workflow/CI - or the owner's repository by its own name, read from `jarvis_github.OWN_REPO` - the read tools that answer about that thing are added to the shown list FIRST and the top-K cap cannot cut them. It adds only card-free reads (never a write tool on its own), it is bounded by the owner's enabled list, and it touches no gate, no tier and no configuration: `check_call` still reads the allowed list, so a hidden tool can still be called and every GitHub write still raises its own card. `feature_guide`'s `is the ... on` hint was also anchored to the end of the sentence - it had matched its own words inside the commit question by accident. #1382 merged before this branch and gave two tools the words `commit` and `defect`, so on today's `main` the false-denial question is shown a GitHub tool again; what the floor still fixes is the class: nothing in any hint knows the owner's repository by NAME, and "branches" matched no hint (that question got a 29-tool full-list fallback). Measured against merged `main`: "which branches have unmerged work?" 29 tools → 1; "which repository holds the owner's project?" from `project_read` alone to `github_list` + `project_read`; the commit question keeps its GitHub tool but loses the stray settings tool; the eight battery questions average 7.4 → 3.9 tools with 1 → 0 full-list fallbacks, while the ordinary controls (weather, timer, notes, arithmetic) still diet to 1-2 tools and an unmatched question still falls back to the whole allowed list.
