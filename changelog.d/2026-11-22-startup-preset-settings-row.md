- **The preset Atlas loads when it starts can now be chosen in Settings (2026-11-22).** A new "Startup preset" row under "The model and cards" lists the PC's ten presets plus "No preset", marks the one saved today (`/api/work`'s own `startup_preset` block), and saves through ONE new narrow desktop command, `set_startup_preset`, which posts one preset id to `/api/work/startup-preset` and returns the route's own JSON unchanged - there is no general "post any route" command. The row says before the press that saving a preset asks first (one card appears in the Atlas bar, on the widget or on the owner's phone Home screen) and that nothing changes until it is approved; choosing "No preset" takes effect at once and asks nothing. The card repeats the PC's own sentence after the answer, so a Denied card is shown as "not changed" rather than guessed at. The read reuses the existing preset read, so this change adds no second read command, no backend change and no HUD change, and the setting is still the same file the chat sentence writes.
