- **The Rust supply-chain check no longer goes red on an advisory that cannot reach a Windows build (2026-11-23).** `RUSTSEC-2026-0594`, published that morning, is a private cookie's AES-GCM nonce repeating in a process that `fork()`s without `exec()`; `cookie` 0.18.2 arrives here transitively through `tauri`, `tauri-runtime` and `wry`, and it was the only reason `cargo deny check advisories` failed on `main` and on every pull request. `jarvis-desktop/src-tauri/deny.toml` now lists it by id with the reason in the file: the advisory's own `[affected]` section names only Unix-like systems (no Windows entry) and its "Who is affected" section exempts applications that never fork, "including all applications on Windows" - which is what this desktop app is. The better fix, `cookie` 0.18.3, could not be taken that day: this machine's cargo had no registry access and its local index cache knew only up to 0.18.2, so the bump waits for the next dependency refresh and the ignore comes out then.
