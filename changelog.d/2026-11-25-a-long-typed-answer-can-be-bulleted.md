- **The long-answer layout dial exists: a typed answer can be bulleted, and the setting is kept in one file (2026-11-25).** `jarvis_answer_style.py` offers three styles - `auto` (a plain sentence first, then a bullet per part once an answer has three or more parts), `bullets` (any answer with more than one part), and `prose` (never a bullet, which adds no prompt note at all, so turning it off restores exactly the bytes the model had before). The lines it would add to a typed turn forbid headings, tables, HTML and nested bullets. **The prompt wiring is not in this change:** the request-shaping suites pin the exact shape of a first question, and inserting a second leading system message broke five of those pins when measured, so the note is deliberately not attached until the ordering has its own change.
