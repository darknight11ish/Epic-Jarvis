- **Settings' Connection card shows a QR code that opens Atlas on your phone (2026-11-25).** "Show a QR code for my phone's browser" sits under **Let my phone reach this** and draws the picture in Rust with the same `qrcodegen` path as phone pairing (`browser_qr.rs`). The code carries THIS computer's own private-network address and nothing else — no token, no one-time key, no query string, never a public tunnel — and the page is handed the finished SVG plus that address, so a photo of the code reveals only what the page already prints and signs nothing in. Scanning it opens Atlas's page in the phone's browser; if that browser is not signed in, the page's own pairing sheet explains it, because a browser's pairing key is minted on this PC at a terminal (`jarvis_devices.py --add-device`) and no route mints one. A blank, wildcard, loopback or home-network address gets the card's plain "nothing for the phone to reach" sentence and no picture, and the code hides itself after a minute with **Hide now**. No route was added and no Android change is implied: the other half is Atlas's own web page in a phone browser, not the app. **Not verified with a real phone camera** — the drawing, the address and every refusal are tested; a scan is owed.
