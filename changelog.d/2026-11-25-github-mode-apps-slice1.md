- **Settings and the phone get the Full GitHub mode row (2026-11-25).** One row on Settings, What asks first, immediately under the GitHub group switch, and the same row read-only on the phone: it says whether full GitHub mode is on, in the PC's own two lines for what it does and where it changes; it turns ON through the same `POST /api/asks_first/tools` route and one-card-plus-Windows-Hello path the group switch uses, with `github_mode` as the id, and OFF is one click from either app, no card. A PC that sends no `github_mode` object draws no row at all, every existing row and word is untouched, and `docs/JARVIS-API.md` §190.14 is the section that says what the mode does and which cards it keeps.
