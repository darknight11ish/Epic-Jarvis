- **The PC can hear "Hey Atlas" (2026-11-25).** The owner's trained wake-word model now ships in this repository (`backend/wakeword/hey_atlas.onnx`, 215,964 bytes, SHA-256 `0DBE0AA5…`) and `[voice] wake_phrase = "hey_atlas"` in `jarvis-framework.toml` switches the PC to it. The shipped default stays `hey_jarvis`, so nothing re-points itself, and a PC still set to the old phrase keeps waking with it. The module refuses the file with a plain sentence if it is missing or is not the pinned bytes, and the transcript check now accepts the name of whichever phrase is configured - without that, "Hey Atlas" would have fired the detector and then been ignored. Settings, the bar, the phone's Settings and Platform checks, the phone's FAQ and `README.md` say "Hey Atlas", and the two copy guards now require it while still forbidding "in training" / "being trained". The phone still listens for "hey Jarvis" only - it was not rebuilt in this change, and `docs/ARCHITECTURE.md` section 8 says why.
