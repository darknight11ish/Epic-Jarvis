- **a date sentence writes a date, and a name sentence writes an alias (2026-11-25).** "add today's date to my mood log" now writes 2026-11-24 instead of the literal words, with yesterday, tomorrow, "last friday" and month-named phrases like "the 3rd of december" computed from the turn's own local clock through datetime and python-dateutil and never guessed, while a phrase with no month in it ("friday at 5") keeps the owner's words because dateutil reads the bare number as a day of the month and wrote a date in the past. "when I say gym I mean my Exercise note" writes Obsidian's own `aliases:` list on that note behind one approval card, appending rather than replacing, and a later "read my gym note" then resolves to that note. A name that already opens a DIFFERENT note is refused in words that name it - "call my Exercise note workout" while Workout.md exists answers "There is already a note called Workout.md, so saying workout would open that one" and writes nothing, because the resolver reads a file's own name before any aliases list and that alias could never win. The writer also refuses a note whose `aliases:` block holds a comment line or a blank line, or is a one-line `[a, b]` list, rather than rebuilding YAML it cannot put back, and writes every name as a quoted scalar so `*`, `&`, a leading `- `, a comma and a `#` are characters in the name. Three delete sentences were read as names and are fixed: "delete all my notes" no longer answers that there is no note called "my", a count in "remove three notes: Ideas, draft and Shopping" is no longer part of the title, and "delete draft and Shopping" no longer falls to the model. Also fixed: "add a line to my mood log" no longer appends the words "a line", "in my Ideas note" no longer reads "Ideas note" as the title (while a title that really ends in "notes", like Release notes.md, still resolves as itself), a note literally called Everything can be deleted again, a phone call ("call my sister about the note tomorrow") is no longer read as a name for a note, and a link keeps its capitals (`[[Exercise]]`, not `[[exercise]]`). A new corpus suite, `backend/test_note_grammar_corpus.py`, pins 62 sentences and the alias writer's frontmatter shapes at 136 checks, and it records the one sentence still refused ("add a note titled X").
