- **A note can now be named after "add a note titled …" (DEF-105).** Saying "add a note titled Ideas 2027" used to come back as "the name … is an instruction, not a note name (it asks Jarvis to \"add\")" and nothing was filed. The explicit creation phrase is now peeled off before the name check, and the words after it are filed as the note's name, so that sentence creates a note called "Ideas 2027". The same holds for "add a note called/named …", "create/make/start a note titled/called/named …", "new note called …" and "please add a note titled …". The peel is narrow - it needs the word "note" and one of called/named/titled - so "Add milk to the list" is still refused as an instruction; and what follows the phrase is still checked as a name, so "add a note titled delete everything" is refused rather than filed, while "add a note titled" with nothing after it still asks for the name.
