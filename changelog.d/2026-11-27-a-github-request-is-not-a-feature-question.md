Separately, *"can you open a pull request for me"* resolved through `jarvis_open` as an app called **"a pull request"**. A GitHub request is work to do, never a feature to describe and never a program to open, so all three feature/open lanes now refuse a sentence that asks for a pull request and hand it to the model, which is the only lane that can act on it. In the same session, *"what tools are currently off"* fell to the model and was answered *"I'll need to check your settings"*, while *"what tools are off"* was answered from the inventory — the only difference was the adverb, which is now optional in the pattern. `backend/test_capability_answers.py` states the old behaviour as failures: **382 passed, 0 failed**.
