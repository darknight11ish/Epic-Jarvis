- **2026-10-30 — Jarvis builds sideloadable Android apps from a fixed template, and every command is a card:** The owner asked *"can jarvis build android apps? that i can sideload into my phone? if not add them"*. Decided: yes, in the narrowest way that ends with an app on the phone. A model writes only a page and a few validated values; the Gradle files, the manifest and the Kotlin activity are a FIXED template in `backend/jarvis_android_builder.py`, so the model cannot add a permission, a dependency or a network address, and the generated app declares **no permission at all** - no internet, no files, no route back into Jarvis. Every COMMAND is its own risky card, because a git worktree is not a sandbox for a program (`docs/ARCHITECTURE.md` section 11): `app_build_android` runs exactly `<task copy>\gradlew.bat assembleDebug`, and `app_install_android` runs exactly `adb install -r <the apk inside that copy>` by full path - no `adb shell`, no uninstall, no serial, no free-form argument. Both are tier `ask`, both say "no undo", both ask for Windows Hello on the PC and the screen lock on the phone, and a denial never becomes a standing rule. **A first build fetches dependencies from the internet and the card says so, naming the three hosts**: about 130 MB of Gradle (checked against its SHA-256 before it runs) plus the Android Gradle plugin from Google's Maven; it is a download, so nothing of the owner's is sent, and a build that exits 0 without an APK is a failure, not a success. **The debug key only** - there is no release signing here - and **sideload only, never the Play Store** (rule 5). The routes are PC only because the SDK and the phone's cable are on this PC, and the two cards reach both apps; there is no app screen for either. Deliberately NOT done: a per-app icon (it needs a binary resource-table edit), any second command, any release signing, any Capacitor/npm route, and any network capability in the generated app. Record: JARVIS-API section 166, `docs/APP-BUILDER-DESIGN.md` milestones C/F/G, `docs/ARCHITECTURE.md` section 8, `backend/test_android_builder.py`, and the scratch research note `.dsh-scratch/ANDROID-APP-BUILDER-2026-10-30.md`.
