- **2026-10-31 — Flexibility with the Obsidian vault, wave 1:** The owner asked for a lot of flexibility with Jarvis and their Obsidian notes. Wave 1 builds create one note, append to any existing note, and add/remove one tag, all single-file writes with ONE approval card, a File Guardian copy first where there are old bytes, an undo receipt (a created note's undo removes exactly that file), and the sha256 the change started from. Rename, move, delete and multi-note/batch changes deliberately stay out until wave 2, when the link repairs a rename needs are built; themes, CSS and templates stay Obsidian's own. No note text goes to a model, a card or a log, and the hidden-lists/Show rules are unchanged.
