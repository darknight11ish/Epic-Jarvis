- **2026-10-31 — "Protected from Jarvis", a list Jarvis may not touch:** The owner asked for a list of file folders, files and programs "that i can manually add to (or ask jarvis to exclude in chat and get a card) that blocks jarvis from having any access (read or write) or the ability to make certain files or folders or programs read only". Decided: ONE store on the PC (`protected-items.json`), kinds folder/file/program, two modes - blocked (no read, no write, no action) and readonly ("see it, never act" for programs); adding by hand on the PC is immediate because it only TIGHTENS what Jarvis may reach, every removal raises ONE card because it LOOSENS, and a chat add raises ONE card before the store changes. Enforcement is one central check called at every named door (documents, file tools, notes, attachments, File Guardian restore, open, UI control, screen/OCR, schedule, pictures), with the gaps this version cannot close written down plainly in `docs/JARVIS-API.md` §170.5 rather than left silent. Both apps read the list; the phone's Remove asks the PC for the same card, and the phone cannot add from Settings because it has no PC file picker - that one route is the desktop's alone on purpose (`docs/ARCHITECTURE.md` §8). Implemented and proved in this repository, not deployed to the owner's live PC by this change.
