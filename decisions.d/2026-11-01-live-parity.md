- **2026-11-01 — Jarvis Live is shown the same tools as typed chat, and its tool limit is a floor rather than a cut:** The owner asked that Jarvis Live be able to "reasonably do anything that jarvis can do through chat". A Live turn already used the same chat route, agent, gate and cards; what narrowed it was the tool list the model was shown - `[live] tool_limit` capped it at 6 names and the cap also cut the diet's full-list fallback, so words the tool diet did not recognise were shown 32 tools typed and 6 spoken (26 hidden, notes, timers, reminders, email, settings and account connection among them), and a Live conversation also carried one tool fewer forward. That was written down on 2026-10-18 as a speed slice, with the note that it "changes what is shown, never what is allowed" - true but irrelevant, because a model cannot call a tool it is not shown. Decided: a Live turn is shown exactly what a typed turn is shown for the same words. `jarvis_live.LIVE_TOOL_FLOOR` equals typed chat's own diet size (8) and `[live] tool_limit` may raise it, never lower it; the full-list fallback is not trimmed; the carried list uses typed chat's cap. What is deliberately kept is the rest of the speed slice - the `[live]` model, its single lane and the 16K window - and the deliberate Live rules: cards stay the same gate cards decided by tapping only, Live still pauses while a card raised since it started waits, a spoken yes is never heard, and the phone still does no speech-to-text. The switched-off persistent-stream path now sends `provenance: "voice"` with `live: true`, the two marks both apps already send, so a streamed Live turn is recognisably spoken instead of looking like an untagged typed turn. Proved by `backend/test_live_parity.py` (tool-list equality over six kinds of question, the floor, the carried list, a whole Live turn reaching the tool path and raising its one card with nothing run first, the fast path's identical PC-state answer, and the kept rules) and by updated assertions in `backend/test_live.py` and `backend/test_agent.py` that had pinned the old cap; no real model, phone or Live session was driven, so that remains NOT-TESTABLE until an owner test.
