- **2026-11-04 — Adopt `waits_for_person` attention-first sorting in the Work pane (pattern 4):** ported from `dsh-superagent`'s `waits_for_person` predicate (Part II pattern 4 of the owner-forwarded `GEMINI-RULINGS-1253-AND-SUPERAGENT-SPEC-2026-11-04`), because a Work pane that lists every background job equally makes healthy work look like work the owner must look at. The list under the Start form is now two sections decided by ONE predicate in ONE shared place per platform (desktop `jarvis-desktop/src/attention.js`; phone `com.jarvis.client.net.JobAttention`): **"Needs you"** holds every job whose approval, an answer, a retry or an unacknowledged failure a person has to look at, drawn first and expanded with the job's own action, and when it is empty it is **not created at all** - no heading, no empty box, no reserved gap, so it takes zero pixels; **"Quiet / healthy"** is ONE collapsed line that opens on a click or tap to the same rows. The contract is `state in ("waiting_approval", "blocked", "needs_input") or (state == "failed" and not dismissed_by_owner)`, and the PC's own optional per-job `waits_for_person` boolean WINS when a payload carries one, with this derivation as the fallback. That fallback is not a stub: no backend in this repository sends the field yet (PR #1148 does not add it), so an older PC must look right rather than broken, and the field is where a later backend can take the decision over. It replaced the single flat list that drew every job the same way, and it deliberately keeps everything else: the order is stable (the read's own order on both sides, so a row never jumps between two reads of the same answer), there is no polling (the existing refresh path rebuilds it), there is no new action and no new approval - a quiet job keeps its Cancel and a parked one keeps exactly its one "Allow once"/"No" pair - and folding the quiet bar only changes a local flag. Its truth table and the zero-pixel empty state are pinned in `jarvis-desktop/tests/attention-first.mjs` (with Playwright DOM checks) and `AttentionFirstTest.kt`.
