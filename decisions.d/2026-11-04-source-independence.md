- **2026-11-04 — Source independence is evidence about who paid, never a trust score:** The owner's clickable-card answer to the unbiased-product-research question was to wire the existing product check AND add the sponsored-article/YouTube layer, so that quality is weighed across independent sources instead of trusting a star rating. This records the decision behind the second half, built as `backend/jarvis_source_independence.py` (shipped whole, byte-identical `jarvis-backend/` twin) and deliberately not wired: one supplied page is read for disclosure wording, affiliate and tracking links, and urgency wording, and the answer is a CLOSED per-source verdict - `disclosed_sponsored`, `likely_monetised_undisclosed`, `affiliate_only`, `no_monetisation_evidence` or `cannot_tell` - each carrying the phrase, snippet or link that produced it. Three rules are the decision, not an implementation detail. First, **evidence only, no aggregate trust score**: there is no score, probability or percentage anywhere, for the reason `docs/DESIGN-PRODUCT-RESEARCH.md` already measured - a single number hides which rule fired and invites over-trust - and `rank_sources()` reports counts of sources and a word-for-word agreement summary instead. Second, **`cannot_tell` is a real answer**: an empty page, a JavaScript shell or a page below the readable-text floor is reported as unchecked and is never counted as independent, because unknown is not the same as clean. Third, **the borrowed patterns are credited**: the shortener, tracking, affiliate-parameter and fake-urgency vocabularies are a Python-native port of dakidarts/dark-radar (MIT), named with its MIT text in `THIRD-PARTY-NOTICES.txt`; no JavaScript is vendored and no dark-radar file is shipped, and the patterns added on top (affiliate-network addresses, redirect wrappers, the shop-tag shape, negated-wording handling) are this repository's own and are named in the same notice. The layer makes no network call, opens no link, resolves no shortened address, plays no video and reads or writes no file; `backend/test_source_independence.py` proves that with a socket/urlopen spy and an AST scan of the module's own imports. No route, model tool, approval card, Settings row or app screen is added by this decision; wiring is the separate lane the owner asked for, and `docs/JARVIS-API.md` is deliberately untouched until there is something to call.
