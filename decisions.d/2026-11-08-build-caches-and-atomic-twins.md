- **2026-11-08 — Build caches live in one shared place, and the self-code map is written with its twin:** Six worktrees' own `src-tauri/target` directories (about 25 GB) took the owner's `C:` drive down to 1.35 GB free and tripped Syncthing's "< 1% free" database halt, and a map regenerated without its `jarvis-backend/` twin cost one full CI cycle on #1214. The rule now: every cargo or Gradle command uses ONE shared cache root (`D:\jarvis-cache\cargo-target` and `D:\jarvis-cache\gradle` on this PC, else one shared folder under the user profile), a subagent deletes any per-worktree target it made before reporting, and `tools/gen_self_code_map.py` writes `backend/jarvis-self-code.json` and `jarvis-backend/jarvis-self-code.json` in the same run, with `--check` refusing when the two differ. The rule is written in `CLAUDE.md`; it replaces per-worktree caching, and nothing about the twin rule itself changed.
