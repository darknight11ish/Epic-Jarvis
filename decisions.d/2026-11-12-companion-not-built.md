- **2026-11-12 — The desktop companion's visual half is not built, and the product says so:** the Roamies-inspired companion (PR #1229) ships as one shipped module (`backend/jarvis_companion.py`), a saved-preferences file and seven chat answers. No window of the desktop app and no screen of either app draws an avatar, a guidance overlay, a cursor ask bar or a 3D card, and the module neither reads another program's controls nor recognises text in a picture. Decided on the 2026-11-13 review of that pull request: **the claims go, not the honesty.** Every companion answer starts from "the desktop companion's drawing and screen half is not built in this copy of Jarvis"; the four switches ship OFF because a switch reading ON would be a presence the product does not have; and a save that fails is reported as a failure, never as "now on". The module keeps **no safety list of its own**: `denied_app_reason()` asks the one enforced desktop hard denylist (`jarvis_ui_control.DENY_PROCESSES` / `DENY_WINDOW_TITLES`, through `denied_process_refusal()`) and reduces a full path to the program's own file name first, because the eight-name list this pull request first shipped allowed `C:\Windows\System32\cmd.exe`, `wt.exe`, `1Password.exe`, `bitwarden.exe` and `keepass.exe` and no caller consulted it. The ten-word `RISKY_WORDS` / `is_risky_action()` pair is removed for the same reason: a bypassable list must never be the thing that guards an action, and with no action here the honest answer is no list at all. **The two change intents are not reads:** `companion_toggle` and `companion_set_style` came off `_PRIVATE_DETERMINISTIC_READS` - they write a settings file, so a private chat now refuses them like every other change, the same rule `read_aloud_set` and `wifi_reconnect_set` are listed under - while the five read intents stay on it and on `READ_ONLY_INTENTS`. The preference file lives in Jarvis's own settings folder (`OPENJARVIS_HOME`, else the two config-folder names, else `~/.openjarvis`), not `~/.jarvis/`, so the suite is hermetic. **The AGPL-3.0-derived geometry and wave are removed, not reworded:** `generate_sphere_points()` and `calculate_wave_displacement()` were line-for-line translations of the Roamies showcase's `showcase/roamies/jarvis.js`, which this MIT-licensed project may not carry, so both are deleted on 2026-11-13 along with the point count they computed, and the overview and the avatar answer now say the geometry and the sound-reactive formula are not here. Recorded here as a "designed, not built" item: the real desktop lane (screen reading, text recognition and a drawing overlay, each behind its own switch and its own card, reusing the enforced denylist) is future work, and no part of the product claims it. `docs/JARVIS-API.md` section 219 is the contract and `docs/ARCHITECTURE.md` section 8 records the one-sided absence; `backend/test_companion.py` is the proof.
