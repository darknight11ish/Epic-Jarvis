  1. **Mobile AI Engine:** llama.cpp GGUF runner (`MobileLlamaEngine.kt`) supporting Q4_K_M / Q8_0 quantizations with optional Vulkan GPU hardware compute, configurable CPU thread count (2, 4, 6), and configurable context window sizes (1024, 2048, 4096).

  4. **Adjustable Settings:** Android Settings plate (`OnDeviceModelPlate.kt`, key `on-device-model`, item index 30) exposing Vulkan GPU toggle, CPU threads chip selector, context size chip selector, auto-sync toggle, offline memory capture toggle, and battery saver guard toggle with SharedPreferences persistence.
  5. **Deterministic Chat & Self-Knowledge Awareness:** Fast-path chat matching in `jarvis_quick.py` and bounded self-fact entries in `jarvis_feature_guide.py` (`SELF_FACT_IDS` and `SELF_FACTS["offline_companion"]`) giving Jarvis immediate, deterministic self-awareness in chat turns without model hallucination.
