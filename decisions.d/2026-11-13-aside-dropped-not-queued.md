- **2026-11-13 — A fixed line that arrives mid-answer is dropped, not queued:** when the owner's PC is already speaking an answer, a timer announcement ("Your timer is done.") or a Jarvis Live line is now dropped rather than spoken over it. Deferring it was the alternative and was turned down: every one of these lines also appears on screen (the timer's own toast, the Live strip, the refusal's notice), so nothing is lost by dropping the sound; a timer that fired minutes into an answer is about now, not about the moment the answer ends; and deferring would need a queue of things to say - a second speech path, which would then talk over the NEXT answer instead. This is the rule the focus callout already followed (`playFocusCallout`), now shared by `sayAside`. Stop is the stronger, separate rule fixed the same day: it ends the answer's speech and marks the turn so the rest is never queued.
