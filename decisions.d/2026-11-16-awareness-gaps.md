- **2026-11-16 — An answer that cannot be read is never guessed:** an awareness question is answered from a real read of this PC or it says plainly that it cannot tell; it never falls through to the model, which cannot measure anything, and it never upgrades what it did read. The 2026-11-15 audit measured eleven questions with **no fixed answer at all** - each one reached the 8B model, which has no way to read a disk, a server or an installed-model list, so whatever it said was invention. This change answers four of them from the read that actually owns each fact: *"what models are loaded"* from Ollama's own `/api/ps` (with **"nothing is loaded right now"** when the list is empty, and the loaded model's name, memory, card share and context when it is not), *"how many models are installed"* from the installed-model list the app already reads, *"what is my disk space"* from the same PC-facts disk read that "how much disk space is left" already uses, so the reply names every drive (the audit's gap was the phrasing; a narrower one-drive answer was dropped rather than added beside the wider one), and *"is ollama running"* from the lane's own `/api/tags` probe - the same read both apps' lane warning makes. Each sentence names the read that answered it, so the words can be checked against the machine. The rule this records is the half the older entries did not cover: **when that read fails, the answer is "I could not read it, so I cannot tell - and I will not guess"**, never a number, a model name or a state borrowed from the configured choice; an empty list that cannot be told apart from a failed read is said as "cannot tell", not as "none". A configured model stays **set to use** and is never called loaded or running (PR #1292's rule), and all four answers are read-only intents, so asking one cannot clear what "cancel that" would undo. Deliberately NOT answered, because the honest source is not on this PC: the phone's own model, whether the phone is connected, the mailbox, which card runs the model, what Jarvis is doing, what it cannot do, and how many interruptions are left - they stay open and are named in the audit rather than filled with a plausible sentence.
