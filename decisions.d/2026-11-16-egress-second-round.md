- **2026-11-16 — The gate's census, and the one browser exception:** Two promises finish the one egress gate. **The census:** `tools/check_egress_gate.py` knew six chatbot API hosts, so a green run meant "nothing among six hosts", not "nothing leaves" - the browser sites, the three keyed web-search providers, `api.github.com`, Google's calendar hosts, the weather, package and map hosts were all invisible. It is now a census: every `.py` under `backend/`, `jarvis-backend/` and `tools/` that names an outbound host must either name `check_egress` in the same file or be on an exact-path allow-list with a written reason, a listed `backend/` path also covers its byte-identical `jarvis-backend/` copy (measured, not assumed), an entry whose file has gone or no longer names a host is reported, and a new unlisted host name fails the run with the file and line. `jarvis_search.py` now asks the gate about the exact address before every keyed search, before the key is resolved; the local SearXNG search deliberately does not, because it never leaves this PC. **The exception:** the browser chatbot drivers type into a company's own web page, which has no API key and no monthly cap on this PC - so the money question could never answer yes and those drivers would be refused for ever. The owner's decision (2026-11-16) is that they may go out when the standing cloud switch is on and Lockdown is off, because the switch being on is their yes. So `check_egress` takes one claim, `no_money_cap="<your own caller name>"`, and the gate accepts it only from the callers named in `NO_MONEY_CAP_CALLERS` (today exactly `jarvis_chatbot_web`, the module every website driver sends through), only when it equals the caller's own name, and only for an address that belongs to no service this PC has settings for - it can never bypass a real monthly cap, Lockdown or the standing switch, and a caller that is not named, or that claims another caller's name, is refused exactly as before. The drivers ask it in `send()` and in `_goto_here()`, and a gate that cannot be loaded is itself a refusal, with nothing typed. If a second kind of caller ever needs this shape that is a new decision, not a new name in the list. What this deliberately does not do: it opens no socket and sends nothing itself, the drivers' own existing checks still run, and the HUD's runtime-built address remains the one path a text census cannot see.
