- **2026-11-16 — Recalled memory is the owner's own data, not outside text:** The taint latch exists to stop OUTSIDE text - a page, an email, a document, a pasted file, tool output - from widening what Jarvis may do. Recalled facts are the owner's own remembered words, learned from his own words only (the 2026-09-24 decision), so they must not take that latch. Measured 2026-11-16: the HUD's memory-injection branch called `jarvis_gate.latch_taint(why="memory_injected")`, and because the latch is ONE boolean with a label no consumer reads, every note write asked for a card (a new note waited on an `edit_vault_note` card) and a setting change refused itself as "shaped by something outside of your direct input". Fixing it has two doors, both in `jarvis_hud.py`: the memory branch no longer latches, and the request handed to `jarvis_agent.run_local_turn` no longer carries the server's own recalled-facts system turn (the turn watch read a system message there as text the APP sent). The every-turn re-latch moves out of the `elif` so it still extends a REAL outside-text latch on memory-injected turns, keeping the 30-minute sliding window exactly as it was. Memory still stays on this PC without the latch, by the two mechanisms that already did that work: while Jarvis injects memory itself the HUD passes `lanes=[]` to `jarvis_router.choose`, and a cloud turn is stripped to user-role messages only, so neither the recalled block nor the local model's restatement of it can travel. A pasted file keeps its own boundary (the router's `file` gate plus the conversation mark, which the 2026-10-30 decision chose IN PLACE OF the process-wide 30-minute latch, so one attachment cannot keep every other chat off the cloud lane), and a page watch, an email-body read and a document read still latch for 30 minutes with the every-turn re-latch. The fix is in the published base and in NO patch, so it reaches a live install through four literal deltas in `tools/hud-deltas/`, carried by `tools/reconcile_live_backend.py`; `backend/test_reconcile_live_backend.py` proves the four reconstruct the base byte for byte.
