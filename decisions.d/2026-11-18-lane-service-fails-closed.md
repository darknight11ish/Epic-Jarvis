- **2026-11-18 — lane_service must fail closed: a lane name the table does not know names no cloud service:** The owner's ruling: `jarvis_chatbot_api.lane_service()` must never turn a lane name it does not recognise into a cloud request. It used to map any unknown name to `DEFAULT_LANE` (or the chosen provider), so `lane_service("qwen3.5:9b")` answered `("deepseek_api", "deepseek-flash")` and a local model's name in a lane field could have sent a private prompt to a cloud service; the HUD's request builder asks `lane_state(lane)` for the address it will open, and a wrong service there is a real egress. From 2026-11-18 only a name in `CLOUD_LANES` names a service. The empty name is the local signal, and every other name - an old `degrade_chain` entry, a local model's name, anything else - returns `("", "")`: no service and no model. No caller may reintroduce a fallback for an unknown name; `DEFAULT_LANE` stays the default for the empty name and for a real lane while no provider is chosen, never a destination for a name the table does not know.
