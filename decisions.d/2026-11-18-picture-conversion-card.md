- **2026-11-18 — Picture conversion: `img2pdf` for the PDF half, `pikepdf` beside it, and one own "ask" action for the file it writes:** The owner asked "can Jarvis convert certain formats of files to other formats? like to pdf from an image and so forth", and the research lane's report settled the tools, so the decisions here are the shape and the guards. (1) **The PDF half is `img2pdf`, never Pillow's PDF writer.** Pillow's `save(..., "PDF")` re-encodes RGB through its JPEG encoder and defaults the page to 72 dpi; img2pdf copies a JPEG's (and JPEG-2000's) own compressed bytes into the PDF, which is the losslessness the feature exists for and which `backend/test_image_convert.py` proves by finding the input bytes inside the output. `pikepdf` (img2pdf's own PDF assembler, QPDF) comes with it and is named in `requirements.txt` as well, because the lock must hold both. (2) **The picture-format half is Pillow, and it must not lie about quality.** PNG/TIFF are lossless; JPEG/WebP/AVIF are lossy and the card and result both say "lossy" and "not identical". Transparency asked into JPEG is flattened onto white and the sentence says "flattened onto white" - the research's finding that the two obvious tools silently re-encode is exactly the failure this sentence rules out. (3) **ONE new gate action, `convert_images`, tier "ask", with no new HTTP route.** The chat tool's ordinary tool-call card is the only permission path; it reuses the existing gate, the existing `my_files` tool and the existing child-program pattern. A new action name was needed because every existing file-writing card is purpose-specific (the notes editor's `edit_vault_note`, `import_notion_export`, `receive_uploaded_document`, `wiki_update`) and its words would be false for a PDF; the module's `prepare()` refuses any tier but "ask" as a belt under the card, so a hand-loosened settings line cannot make a file write cardless. (4) **Never overwrite: a numbered name, an explicit refusal, and `O_EXCL`.** A chosen name that is taken becomes `photo (2).pdf` and the card says so; a path the caller named that exists is refused rather than silently renamed; and the write itself opens the destination with `O_CREAT | O_EXCL`, so a file that appears while the card is up is refused too. (5) **Licences and limits.** img2pdf is LGPL-3.0 and pikepdf/QPDF is MPL-2.0: ordinary pip dependencies of a local, non-commercial program, never linked into a Jarvis binary, credited in `THIRD-PARTY-NOTICES.txt` - which also gains the FFmpeg credit a shipped feature had been missing, with the rule that the GPLv3 build on this PC is required and must never be bundled. HEIC is NOT read (the maintained decoder is handed to the phone's own setting instead), the PDF's page size follows each picture's DPI, and this is chat-only with no route of its own.
