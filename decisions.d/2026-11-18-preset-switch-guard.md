- **2026-11-18 — A preset apply has to PROVE the lane, and a tripwire probe must never name no window:** `apply_preset` now reads the target lane's `/api/ps` through a `verify_lane` seam and refuses - rolling the model record, the lane pointer and the chosen preset back - unless the lane shows the model the preset names, with no CPU spill and at a window no smaller than the preset's own. The judgement calls in that check, all made against the A2 field test (DEF-088: a `general` apply reported success while 11436 served the pooled coder at 8,192): (1) **an EMPTY lane is not a failure.** A preset apply records which model chat should use; Ollama loads it on the next turn at the lane's own window, so failing "nothing is loaded" would red-flag the most ordinary apply there is. Only a model that is not the preset's, any spill at all, a window smaller than the preset names, or a lane that does not answer at all is a failure - "could not tell" is never a pass. (2) **A probe that cannot name the window is not sent.** Every tripwire request now carries `options.num_ctx` from the lane's own configured window, and an unknown window raises instead of falling back to Ollama's default, because that default is exactly what replaced 196,608 with 8,192. (3) **A pooled outgoing model is SKIPPED, not re-aimed at the pooled lane.** The alternative - probing it on the pooled address - would still load a stale name there and cannot answer "how did the old model answer" after `apply_preset` has stopped that server; a skip cannot load the wrong model on the wrong card even when the pooled lane is down. (4) **The check runs on the owner's PC only.** Inside a suite the default reader says `checked: false` and that it is NOT a pass, the same `JARVIS_SUITE_RUNNING` marker `_warm_on_startup` uses; a suite that wants the real reader passes `_default_verify_lane` itself with a fake lane of its own, which is how `backend/test_preset_switch_lane_guard.py` proves it. This is a bug fix with no permission, route or approval-tier change: the two `switch_model` cards, the app-click rule, and the receipt/Undo path are exactly as they were.
