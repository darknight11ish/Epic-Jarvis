- **2026-11-21 — A dynamically loaded module must be registered before it runs:** the auto-finish's deploy route failed with "the deploy route itself failed (AttributeError: 'NoneType' object has no attribute '__dict__')" because the loader executed the reconcile module without putting it in `sys.modules`; Python 3.12's dataclasses look their own module up there. The rule: load through the module system, not around it, and test a loader against the real module - a faked module cannot prove the load.
