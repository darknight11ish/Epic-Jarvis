- **2026-11-21 — A release's new tools are added to the owner's config by one explicit additive step:** measured on the live install, PM2's eight project tools were ON in the published config but absent from the owner's `[tools] enabled` list, and because the deploy deliberately never writes that file the feature could not be used at all. The rule now: between "a release ships a new ON tool" and "the owner's config lists it" there is exactly one tool, `tools/enable_new_tools.py`, which adds only the tools it is told to add, never re-enables one the owner turned off, and never touches any other setting; the update flow calls it with the release's new tool names.
