- **2026-11-25 — The Simple layout is first; being first is not being the default:** the owner's words were "also add a simple layout and have it at the top of layout presets for jarvis hud on the desktop. have this be simple with just the essential tools and not too much customization or options". **What was decided:** a new built-in id `simple`, named "Simple", is first in `LAYOUT_CHOICES`, `PRESETS`, `contract/hud-presets.json` and `hud_layout.rs`'s accepted list, and no existing preset is renamed, reordered or removed. "Essential tools" is the four protected cards (Stop everything, the Atlas bar, approvals, voice controls) plus the conversation and its ask box; every other registry card is NAMED and off, because `hud-edit.js` re-adds an unnamed movable card visible and the first Edit HUD visit would otherwise undo the layout. It reuses the page's own `single-stage-bento` shell at comfortable density, so it needs no new page markup or CSS and the page-owned AI Mode, Open Brain and Settings doors remain the way to memory and configuration. **Why first is not the same as default:** `DEFAULT_PRESET_ID` used to be `PRESETS[0].id`, so putting Simple at the top would also have re-pointed every fallback at it, including the old `jarvis.hud.layout` migration and every unreadable or wrong-version document, silently changing what stored layouts mean for an owner who already had one. The constant is now explicitly `"cockpit"`: a document that NAMES a layout still wins, and only a genuinely choiceless document lands where it always did. This keeps the owner's "at the top" instruction and leaves the everyday layout as the fallback the owner never asked to change. **Proved:** `tests/hud-simple-layout.mjs` checks the first-row order, the composition, `DEFAULT_PRESET_ID === "cockpit"`, the real page applying Simple, and a real selection from the one Presets menu that saves the Simple document and comes back to it; `hud-layout.mjs` pins the eight ids in order. **Limits:** headless Chromium, not the installed WebView2 window, and the owner's live install is untouched by this branch.
