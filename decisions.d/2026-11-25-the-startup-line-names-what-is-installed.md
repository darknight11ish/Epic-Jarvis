- **2026-11-25 — The startup line names what is installed, never the crate's placeholder:** The one line where the app says what it is must be the version the installer wrote, because the update answer and the preflight both compare that line against the backend and the phone. Reading the crate version meant a line that could never match a real install, so the honest answer to "did my update finish" was "I cannot tell" on the owner's own PC. A source-pin test now reads `lib.rs` and fails if the placeholder macro returns, which is cheaper than discovering it through another round of field testing.
