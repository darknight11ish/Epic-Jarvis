## Rules worth repeating (details in CLAUDE.md and the queue doc)

- Never open a pull request unless the owner asks; the ONE final pull request is the exception.
- Numbers come from code, never the model. Money and health figures are screen-only (never read
  aloud, remembered, sent to search or a chatbot). No streaks or guilt. No outside JS library or
  bundler in the desktop app. No bank connections. Nothing stored as runnable SQL.
- Every new feature gets its own audit without being asked.
- After editing any `backend/*.patch`, run `python3 tools/build_patch_history.py` (`git fetch
  --unshallow origin` first if the clone is shallow).
- The Android phone app can only be compiled by GitHub Actions; local Kotlin work is limited to
  pure logic compiled with the Kotlin 2.0.21 jars (a Gradle install has them in its `lib`
  folder). Compose screens are read by eye until CI runs.
- Only the newest stable Rust matches CI. Rust checks target Windows: `cargo fmt --check`,
  `cargo check` and `cargo clippy -D warnings` with `--target x86_64-pc-windows-msvc --all-targets`
  in `jarvis-desktop/src-tauri`. `cargo test` needs Windows.
