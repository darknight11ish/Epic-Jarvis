## 3. Hazards — things this session got wrong, so the next one does not

1. **`8969a1d5` was a mass deletion** (11 files, 531,882 lines, including
   `docs/SOURCE-BUNDLE.md`). It was pushed by accident and undone in
   `d0cdb7d8`. Do not resurrect it. The cause: a `git revert` aborted because
   the working tree was dirty, and the script committed anyway. **Check
   `git status` is clean before any revert, and never commit after a failed
   revert.**
2. **Do not run a repo-modifying generator while suites or the patcher are
   running.** `tools/build_patch_history.py` wrote a partial history once
   because of this, deleting `backend/patch-history/index.tsv`.
3. **Editing a patch file is two changes**: the patch, and its record. Run
   `py -3 tools/build_patch_history.py` afterwards and commit
   `backend/patch-history`. `test_patch_history.py` is the only thing that
   catches it.
4. **A patch's context must be checked against the owner's real backend
   files**, not only the stack the test suites rehearse. `tutorials.patch` was
   anchored on the wrong install block (retirement, 40 lines too early) because
   it was built from the rehearsal stand-in; the fix was to read the real
   `jarvis_hud.py` and anchor on `quiz-cloud`, the block actually before the
   socket. Verify with `git apply --check` against a copy of the real file.
5. **A new Tauri command needs four places**, each policed differently:
   `lib.rs`'s `generate_handler!`, `build.rs`'s command list
   (`tools/check_command_acl.py`), `permissions/autogenerated/<cmd>.toml`, and
   the set in `permissions/surfaces.toml` named by `capabilities/brain.json`.
   `cargo fmt --check` also polices `build.rs`'s formatting — run
   `cargo fmt`, `cargo clippy --all-targets -- -D warnings` and
   `check_command_acl.py` **before pushing**, not after CI says so.
6. **A new patch needs five places**: the patcher's list
   (`scripts/apply-patches.ps1`), `$SHIPPED` in that script, `SHIPPED` in
   `backend/_where.py`, the follower allow-list in `backend/test_devices.py`,
   and the `later` set in `backend/test_referee.py`.
7. **A new phone menu entry is generated**, not hand-written: the source is
   `backend/jarvis_menus.py`, and `tools/gen_menu_cases.py` writes the phone's
   `MenuCatalog.kt`, the desktop's `menu-catalog.js` and both
   `menu-cases.json` fixtures. A spoken name must be unique — "faq" was refused
   because another menu already claimed it.
8. **`main` carries two extra commits** from this session's mistake
   (`44169863` and its revert `686dc5f8`). The owner chose to leave them; the
   **content is identical to `01425b52`**. Do not force-push without asking.
9. **`test_installed_stand_in.py` needs the patch stack to write exactly one
   `_loopback_companion(bind, HUD_PORT, Handler)` line.** A hunk that repeats it
   as trailing context fails; three lines before and one after is the shape
   that works.
