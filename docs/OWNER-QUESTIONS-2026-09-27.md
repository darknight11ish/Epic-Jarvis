## Memory and backup

**1. The re-ranker.** No longer a question: it is now OFF until your PC's
self-test shows it helps (2026-09-26), because you decided every memory
change must be measured first. `docs/MEMORY-SCOREBOARD.md` has the one line
that runs the test, and the one line that turns it on if it wins.

**2. Back up Jarvis's memory to NordLocker (or another cloud you pick).**
Today this breaks rule 1 ("stored memory never leaves the PC"). A safe way
exists: Jarvis writes ONE backup file, locked with a recovery code only you
have, into a folder you choose. If that folder is one NordLocker syncs,
NordLocker uploads it, locked again by NordLocker. Nobody at Nord can read
it, and nor could anyone who stole it. Two honest limits: if you lose the
recovery code, the backup is useless; and a fact you "Erase" stays inside
older backups until they are deleted (Jarvis would keep only the last few).
- **a. Yes - a locked backup file into a folder I pick; I accept the change
  to rule 1 for that one file** (recommended)
- b. Only to a USB drive or another folder on this PC, never a cloud
- c. No backups for now

(Report: `docs/CUTTING-EDGE-2026-09-26-round2-trust.md`, idea 2. I have not
checked how NordLocker's Windows app exposes its folders; if it only accepts
files dragged into its window, you would drag the backup file in yourself.)
