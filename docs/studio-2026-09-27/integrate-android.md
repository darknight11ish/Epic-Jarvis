# Integration scout: Android, condensed
Already built with platform APIs: Glance widgets (ApprovalWidget, QuickLinkWidget), assistant role w/o STT (assistant/JarvisVoiceInteraction*), QS tile (LinkTileService), share target, Also on my phone (AlsoOnPhone.kt), watch switch (WatchNotify.kt). Gaps: QR scan, bubbles, notification reading, per-approval biometric key.
1. QR pairing: ZXing core 3.5.4 (Apache, pure Java 610 KB) + CameraX 1.6.2; adapt GrapheneOS Camera analyzer/QRAnalyzer.kt (MIT, 122 lines). Strip all Log lines (decoded text = secret). CI should print merged manifest to confirm CameraX has no INTERNET/telemetry. Fallback zxing-android-embedded 4.3.0 (stale). Skip zxing-cpp (native).
2. Bubbles: adapt OpenClaw ConversationNotifications.kt (MIT) + SociaLite NotificationHelper.kt (Apache). Two more gaps beyond MessagingStyle: WakeWordService.publishBubbleShortcut() sets no Person on shortcut (required); MainActivity lacks allowEmbedded="true" (required), singleTask inside bubble unverified. Use setAllowGeneratedReplies(false) (watch voice replies vs no-STT rule - owner's call).
3. Notification reading: AOSP ExtServices LegacyOtpDetector.java + NotificationOtpDetectionHelper.java (Apache) for OTP masking on-phone; OpenClaw app allow-list/picker (MIT). Android 15 OTP hiding relies on Android System Intelligence, absent on GrapheneOS. No "finance" category -> "never banking" rests on allow-list + warning. "Allow restricted settings" may be needed.
4. Biometric key per risky approval: androidx.biometric 1.1.0 already supports CryptoObject(Signature); adapt android/security-samples CryptographyManager.kt (Apache). GrapheneOS key attestation reports "SelfSigned" boot state - PC check must accept it when boot key matches GrapheneOS list (search snippets only). Auditor (MIT) reference.
Rejected: ML Kit / quickie (Play Services), Tasker lib (no licence/GPL), Android Auto messaging (Google voice service, rule 1 - don't add car declaration), Wear OS app (Play Services), GPL apps ideas only.
GrapheneOS: no calendar app shipped -> Also on my phone calendar half shows "no calendar app" until e.g. Etar installed; add line to GRAPHENEOS.md.
Order (fewest CI trips): bubble fixes, OTP masking, biometric key, then CameraX+ZXing.
