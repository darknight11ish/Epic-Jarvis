hey_atlas.onnx is NOT openWakeWord's (added 2026-11-25). It is the owner's own
"Hey Atlas" model, trained on this PC with openWakeWord's openwakeword/train.py
v0.6.0 on openWakeWord's front end; the phone's spotter scores it instead of
hey_jarvis_v0.1.onnx. 215,964 bytes, SHA-256
0DBE0AA5DAF88538A4D368B5DF1654CDAED7CB9AEF8110A600735F6389CE2FBD - the same
bytes the PC holds at backend/wakeword/hey_atlas.onnx. It is treated as
CC BY-NC-SA 4.0 too, because its negative features derive from the
davidscripka/openwakeword_features dataset released under that licence (the
training folder's REPORT.md section 4 records the reasoning).

NON-COMMERCIAL. This app is a non-commercial, sideloaded build (rule 5), and
these files are the reason it has to stay that way while they are in it.

The same files are what the PC uses (voice-models\wakeword), so the
phone and the PC give the same score for the same sound. hey_jarvis_v0.1.onnx
stays here although no code on the phone loads it any more: it is this
repository's only real copy of openWakeWord's bytes, and the two backend
wake-word suites build a fake PC model folder from it.

stop_head.bin is not openWakeWord's. It is Jarvis's own small "stop" model
(tools/train_stopword.py), trained on openWakeWord embeddings of synthetic
voices - Piper's LibriTTS-R voice (LibriTTS-R, CC BY 4.0, Koizumi et al.,
2023) and Kokoro v0.19 (Apache-2.0). It sits on the embedding model above,
so treat it under the same CC BY-NC-SA 4.0 terms. The PC holds the same
bytes in backend/jarvis_stopword.py.
