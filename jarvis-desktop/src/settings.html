Connection

Where the backend is. The token is held here and injected into the HUD at load; it is never written to that page's storage and never shown again once saved.

Only fill this in if you use Tailscale and want your phone to talk to Jarvis too. Type this computer's own Tailscale address here — it looks like 100.x.x.x, and you can find it in the Tailscale app. Leave it blank and nothing changes: Jarvis stays reachable from this computer alone, which is the default and the safe choice. This never opens Jarvis to the whole internet, or even to your home Wi-Fi — only to devices on your own Tailscale network.

Appearance

The theme applies to every window at once — the spotlight, the widget, the Brain and this one. High contrast is held to a stricter standard than the others: every text pair in it clears 7:1 against both a dark and a light desktop, which matters because these windows are transparent and the wallpaper behind them is not ours to choose.

Updates

Jarvis Desktop can look at its GitHub releases and tell you when a newer build exists. It will not install one. Checking sends a single request carrying nothing but the request itself — no identifier, no telemetry, no account — and installing is the button below, pressed by you. An update replaces the program, which is the largest single change anything here can make to this machine, and nothing in Jarvis does that on a timer.

Release notes

Shortcuts

Global accelerators: they work whatever window has focus, which also means only one application on the machine can hold each combination. If one shows as in use, something else claimed it first — Alt+Space in particular is taken by PowerToys Run and, on recent Windows 11 builds, by the Copilot app. Everything here is also reachable from the tray icon, always.

Every shortcut needs a modifier. A bare key bound globally would swallow that key everywhere on the machine, including in the box you would use to change it back.

Backend

Off by default, and it stays off unless you switch it on here. With it on, Jarvis Desktop starts the backend when it launches — unless something is already listening, in which case it attaches to that instead of running a second one against the same approval queue. Quitting asks the backend to stop, so the model comes off the GPU, and terminates the process tree only if asking did not work. A backend you started yourself is never adopted and never stopped.

—

Startup and logs

Jarvis writes what it is doing to a file. If the backend refuses to start, the reason is in backend.log — before this existed there was nowhere for it to go, because a released Windows app has no console. Both files are plain text and nothing in them is hidden or scrambled, so read one before you send it to anybody.

Jarvis will be running after a restart. It does not promise to be first — other startup programs are racing it for the Alt+Space shortcut, and whoever asks first wins.
