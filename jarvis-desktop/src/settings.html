Connection

Where Jarvis is running. A token you type here is kept in Windows Credential Manager (where Windows keeps saved passwords), not in a plain file.

Only an address on your own networks is accepted: this PC, your home network, Tailscale or NordVPN Meshnet. An address on the open internet, a public tunnel such as ngrok or Cloudflare included, is refused, so your token is never sent there.

Jarvis makes its own token the first time it runs and keeps it in Windows Credential Manager too, as Jarvis Backend/pairing token. This app reads it from there, so you only need to paste one here if you changed it. Clear token forgets one you typed here and goes back to Jarvis's own.

Your phone needs the same token

Type it into the phone's Token box. It hides itself after a minute. There is no Copy button on purpose: Windows keeps what you copy in its clipboard history, and can send it to your other devices with cloud clipboard, where the token would stay long after this. Anyone who has it can use Jarvis, so do not send it to yourself in a chat app or an email either.

Only fill this in if you use Tailscale or NordVPN Meshnet and want your phone to talk to Jarvis too. Type this computer's own address on that private network here — it looks like 100.x.x.x, and the Tailscale or NordVPN app shows it. Leave it blank and nothing changes: Jarvis stays reachable from this computer alone, which is the default and the safe choice. This never opens Jarvis to the whole internet, or even to your home Wi-Fi — only to your own devices on that private network.

On the phone, type this computer's name, not the number. That is the Tailscale name ending in .ts.net, or the Meshnet name ending in .nord (for example marioirelan11-alps.nord), followed by :4719.

Shortcuts

Keyboard shortcuts that work in any program. Only one program can hold each one, so if a shortcut says in use, another program took it first — Alt+Space is often taken by PowerToys Run or the Copilot app. Pick a different one and press Save shortcuts. Summon Jarvis, the widget and Stop everything are also in the tray menu.

Each shortcut needs Ctrl, Alt, Shift or Win. A single key on its own would stop working everywhere else on the computer.

Security

Windows Hello is how Windows checks it is you: your Windows PIN, a fingerprint or your face - whatever this PC has. These settings are for this PC only; your phone has its own fingerprint settings. Turning something on happens at once. Turning something off, or making it wait longer, asks Windows Hello first.

                                      Frequently asked questions

                                      Answers specific to this program, the one running on this computer. Jarvis on your phone is a different app with its own FAQ, because the two run into different problems.

                                      Does anything I say to Jarvis leave this computer?

                                      No, not on its own. Jarvis answers using a language model that runs on this machine. It only reaches the internet for something specific, and only after it explains what it needs and you say yes — there is no standing permission to go online, and this program never opens a public tunnel to itself.

                                      Where do I approve or deny what Jarvis wants to do?

                                      On a card. When Jarvis wants to do something that is not completely safe, it stops, and a card waits for you in the Jarvis bar, on the widget, or on your phone's Home screen (Alt+Space opens the Jarvis bar). For anything important Windows also shows a notification. Press Approve or Deny on the card; the notification can only Deny. Nothing runs until you decide, one thing at a time. An email Jarvis wants to send is approved in the Jarvis bar, where you can read all of it first.

                                      Why is there no "approve everything" button?

                                      On purpose. Anything Jarvis wants to do that is not completely safe stops and asks first, one action at a time. A single button to wave all of those through would undo that protection, so this program is built with no way to add one, anywhere in it.

                                      My Alt+Space shortcut does not do anything.

                                      Something else on this computer has already claimed that combination — usually PowerToys Run, or on recent Windows 11 builds, the Copilot app. Open Shortcuts above: a binding that is not working says in use there. Pick a different combination and press Save shortcuts.

                                      Can my phone talk to Jarvis?

                                      Yes, over Tailscale or NordVPN Meshnet — a private network between only the devices you own, never the open internet. Turn it on above, in Connection, under "Let my phone reach this", by typing this computer's own address on that network (the 100.x.x.x number). Then, on the phone, type this computer's name, not the number: the Tailscale name ending in .ts.net, or the Meshnet name ending in .nord (like marioirelan11-alps.nord), followed by :4719. The phone also needs the token: press Show the token for my phone above. Leave the box blank and nothing changes: Jarvis stays reachable from this computer alone.

                                      How does talking to Jarvis work?

                                      Hold the microphone button in the Jarvis bar and speak, then let go to send. With the button selected, holding Space or Enter works too. The microphone button in the big HUD window opens the Jarvis bar with its microphone ready, so both lead to the same place. The recording is made on this computer and goes only to Jarvis on this computer — never to Microsoft, Google or anyone else. Listening for "hey Jarvis", the button next to the microphone, is off until you turn it on; the first time, it shows you an approval card instead of listening. While it is on, what the microphone hears goes only to Jarvis on this computer, which ignores anything that does not start with "hey Jarvis". Windows dictation is not used, because it sends your voice to a company's servers to turn it into text.

                                      Jarvis suddenly got slow. What happened?

                                      Open the Brain window → Faculties → Models. If the language model has fallen off the graphics card onto the processor instead, there is a yellow line at the top of that list saying so, with the percentage. That is almost always the cause — a graphics card doing the work is fast, a processor doing the same work is not.

                                      What is the difference between Quiet and Standby?

                                      Both are ways for Jarvis to use less power while you are not using it. Quiet stops the things Jarvis does on its own in the background, but keeps the model loaded, so it still answers you instantly. Standby also unloads the model from the graphics card — the real drop in power use — at the cost of a slower first answer (five to fifteen seconds) after you wake it back up. To switch, right-click the Jarvis icon in the taskbar corner and choose Change power mode, or use the buttons on the phone's Brain screen. This needs the backend's power-mode patch; without it, you are told so. Waking from Standby loads the model again straight away, so the first answer after waking is quick. To go on Standby every night and wake every morning, set up a Standby schedule in the Brain, Work tab, under Coming up (the phone has it under Coming up on its Brain screen); it is set up at once, with no approval card, and deleting it is instant.

                                      Will Jarvis update itself without asking?

                                      No. Update checks are not set up yet for this copy (see Updates above), and even once they are, JarvisJarvis only tells you a newer version exists. It never installs one on its own. Installing is always the Install button, pressed by you.

                                      I closed the window, but Jarvis is still running. Is that a bug?

                                      No — that is how this program is built. Closing any window, including the main assistant window's own close button, just hides it; Jarvis keeps running so it can still answer you instantly. To actually quit, use "Quit" on the tray icon, near your clock.

                                      Is my pairing token safe?

                                      It is kept in Windows Credential Manager, the part of Windows that holds saved passwords - not in a plain-text file. This app sends it only to the Jarvis address set above, and never writes it to its logs. Show the token for my phone shows it for a minute so you can type it into the phone; there is no Copy button, because anything copied stays in Windows' clipboard history. Anyone signed in to this computer as you can read it, the same as your other saved passwords, so keep your Windows account password-protected. One exception: if the Token line above says Jarvis's own token is still in its old plain-text file, run apply-patches.ps1 to update the backend, which moves it into Credential Manager.

                                      More options Letting this app start Jarvis, starting with Windows, and the log files.

                                      Starting Jarvis for you

                                      Off unless you turn it on here. With it on, this app starts Jarvis when it opens — unless Jarvis is already running, in which case it uses that one instead of starting a second. Quitting asks Jarvis to stop, so the model leaves the graphics card, and forces it to close only if asking did not work. A Jarvis you started yourself is never taken over and never stopped.

                                      The full path to the real python.exe, not the word python on its own: on a fresh Windows that is a Microsoft Store shortcut, not Python. To find the path, run this in PowerShell: py -3 -c "import sys; print(sys.executable)"

                                      Technical detail

                                      Startup and logs

                                      Jarvis writes what it is doing to a file. If Jarvis refuses to start, the reason is in backend.log. Both files are plain text and nothing in them is hidden or scrambled, so read one before you send it to anybody.

                                      Jarvis will be running after a restart. It does not promise to be first — other startup programs are racing it for the Alt+Space shortcut, and whoever asks first wins.

                                      About Jarvis

                                      A local-first personal assistant. A Python backend on this computer, this Tauri shell around it, and a language model that runs here rather than in a data centre somewhere else. Nothing private leaves this machine on its own, there is no public tunnel into this program, there are no API keys built into it, and there is no "approve everything" control anywhere in it — every action Jarvis wants to take stops and asks first, one action at a time.
