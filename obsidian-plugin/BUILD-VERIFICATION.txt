STACKED CHANGE 0.1.2 - READ-ONLY OBSIDIAN LINK + THE FINAL AUDIT'S FIXES (2026-10-31)
-------------------------------------------------------------------------------------
This section is appended on the stacked branch `feat/obsidian-plugin-uri-open-2026-10-31`,
which sits on top of the commit recorded above (same base 66d114038). It adds one
read-only feature and fixes the findings of the independent final audit (that

WHAT CHANGED (all inside obsidian-plugin/; the one changelog.d fragment is separate):
  - NEW read-only feature: the command "Copy an Obsidian link to this note
    (read-only)" copies `obsidian://open?vault=<vault name>&file=<path>` to the
    clipboard (a #Heading may follow the file). The pure helpers `obsidianOpenUri`
    and `obsidianUriAction` live in src/protocol.ts. It builds ONLY the `open`
    action: no `new`, `daily`, `unique`, `prepend` or `append` link is ever built,
    because those write a note instantly and would bypass Jarvis's one card, the
    File Guardian copy and Undo. A unit test and the source-text safety test pin it.
  - AUDIT FIX (MEDIUM): the waiting-card poll is now inside the try/catch of
    performWrite/performWriteUnhashed. A backend restart while a card waits now
    shows "Lost contact with Jarvis while checking the card ... The write may
    still have happened" instead of freezing the panel on "Waiting" forever (and
    logging an unhandled rejection).
  - AUDIT FIX (LOW-MEDIUM): ONE write at a time. A `writeBusy` guard refuses a
    second edit while the first card waits, saying so plainly; the backend would
    refuse the loser with its own hash check, so this is UI clarity, not safety.
  - AUDIT FIX (LOW): performWrite takes the target path the edit was started for,
    and the Replace and Tag dialogs pass the path they captured when they opened,
    so a note switch mid-dialog cannot read a different note's hash (previously a
    misleading 409; never a wrong write).
  - AUDIT FIX (LOW): a very fast `denied` or `failed` answer on a write route now
    maps to kind denied/failed, not to "error".
  - AUDIT FIX (LOW): the template "Create note" button is disabled when no listed
    template can be read (all "Jarvis only") and when the selected option is
    disabled; the offered new-note path follows the chosen template until the
    owner types one.
  - AUDIT CLEANUP: removed the never-assigned `refreshTimer` field, the unused
    `baseUrl()` method and the now-unused `normalizeBackendUrl` import in
    src/main.ts. `onunload()` stays (empty, documented) because Obsidian's
    register* calls clean up.
  - VERSION 0.1.2 in manifest.json, package.json, package-lock.json and
    versions.json.
